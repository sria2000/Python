# Python Program - Roller Coaster Height Checker

This program checks whether a person is tall enough to ride a roller coaster.

The minimum required height is **120 cm**.

---

# Python Program

```python
# Enter the height of the person.
# If the height is 120 cm or more, they can ride.
# Otherwise, tell them how many centimetres they are short.

height = float(input("What's your height (in cm)? "))

if height >= 120:
    print("🎉 Yaay!! You can ride the game.")
else:
    short_by = int(120 - height)
    print(f"Oops! You are short by {short_by} cm. Come back next year!")
```

# How the Program Works

## Step 1 - Read the User's Height

```python
height = float(input("What's your height (in cm)? "))
```

- `input()` reads the user's input as a string.
- `float()` converts it into a decimal number.

Example

```
Input

125

Stored Value

125.0
```

---

## Step 2 - Check the Height

```python
if height >= 120:
```

If the person's height is **120 cm or more**, they are allowed on the ride.

Example

```
130 >= 120

True
```

---

## Step 3 - Display the Success Message

```python
print("🎉 Yaay!! You can ride the game.")
```

Output

```text
🎉 Yaay!! You can ride the game.
```

---

## Step 4 - Calculate How Many Centimetres Short

If the height is less than **120 cm**, the `else` block runs.

```python
short_by = int(120 - height)
```

Example

```
Height = 115

120 - 115

= 5
```

---

## Step 5 - Display the Result

```python
print(f"Oops! You are short by {short_by} cm. Come back next year!")
```

Output

```text
Oops! You are short by 5 cm. Come back next year!
```

The `f` before the string allows you to insert the value of `short_by` directly into the message.

# Understanding the `if...else` Statement

```python
if condition:
    # Executes if the condition is True
else:
    # Executes if the condition is False
```

In this program:

```python
if height >= 120:
    print("You can ride.")
else:
    print("You cannot ride.")
```

Only **one** of the two code blocks will execute.

# Tips for Beginners

- `>=` means **greater than or equal to**.
- The `if` block runs only when the condition is **True**.
- The `else` block runs when the condition is **False**.
- Use meaningful variable names such as `height` and `short_by`.
- `f`-strings make it easy to include variables in output messages.
- `float()` allows users to enter decimal values like `119.5`.

---

# Common Beginner Mistakes

### ❌ Using `=` Instead of `==` or `>=`

Incorrect

```python
if height = 120:
```

Correct

```python
if height >= 120:
```

---

### ❌ Forgetting Indentation

Incorrect

```python
if height >= 120:
print("You can ride")
```

Correct

```python
if height >= 120:
    print("You can ride")
```

---

### ❌ Forgetting to Convert User Input

Incorrect

```python
height = input("Enter height")
```

Correct

```python
height = float(input("Enter height"))
```
