# Python Conditional Statements, Logical Operators, Code Blocks & Scope

Conditional statements allow your program to make decisions based on whether a condition is **True** or **False**.

---

# Conditional Statements

A conditional statement executes different blocks of code depending on whether a condition evaluates to **True** or **False**.

## Syntax

```python
if condition:
    # Code to execute if condition is True
else:
    # Code to execute if condition is False
```

---

## Example 1

```python
age = 18

if age >= 18:
    print("You can vote.")
else:
    print("You cannot vote.")
```

Output

```text
You can vote.
```

---

## Example 2

```python
temperature = 15

if temperature > 25:
    print("It's hot.")
else:
    print("It's cold.")
```

Output

```text
It's cold.
```

---

# Comparison Operators

Comparison operators compare two values and return either **True** or **False**.

| Operator | Meaning | Example |
|----------|---------|---------|
| `==` | Equal to | `a == b` |
| `!=` | Not equal to | `a != b` |
| `>` | Greater than | `a > b` |
| `<` | Less than | `a < b` |
| `>=` | Greater than or equal to | `a >= b` |
| `<=` | Less than or equal to | `a <= b` |

Example

```python
a = 12

print(a > 15)
```

Output

```text
False
```

---

# Nested If Statements

An `if` statement can be placed inside another `if` statement.

## Syntax

```python
if condition1:
    if condition2:
        # Execute if both conditions are True
    else:
        # Execute if condition2 is False
else:
    # Execute if condition1 is False
```

---

## Example

```python
age = 20
has_license = True

if age >= 18:
    if has_license:
        print("You can drive.")
    else:
        print("Get a driving licence first.")
else:
    print("You are too young to drive.")
```

Output

```text
You can drive.
```

---

# Multiple Conditions

You can test multiple conditions using logical operators.

## Example

```python
age = 25
salary = 50000

if age > 18 and salary > 30000:
    print("Loan Approved")
else:
    print("Loan Rejected")
```

Output

```text
Loan Approved
```

---

# elif (Else If)

Use `elif` when you have multiple conditions to check.

```python
marks = 75

if marks >= 90:
    print("Grade A")
elif marks >= 75:
    print("Grade B")
elif marks >= 60:
    print("Grade C")
else:
    print("Fail")
```

Output

```text
Grade B
```

---

# Logical Operators

Logical operators combine multiple conditions.

There are three logical operators:

- `and`
- `or`
- `not`

---

# AND Operator

Both conditions must be **True**.

```python
a = 12

print(a > 10 and a < 13)
```

Output

```text
True
```

### Truth Table

| Condition 1 | Condition 2 | Result |
|-------------|-------------|--------|
| True | True | ✅ True |
| True | False | ❌ False |
| False | True | ❌ False |
| False | False | ❌ False |

---

# OR Operator

Only one condition needs to be **True**.

Example

```python
age = 15

print(age < 18 or age > 60)
```

Output

```text
True
```

### Truth Table

| Condition 1 | Condition 2 | Result |
|-------------|-------------|--------|
| True | True | ✅ True |
| True | False | ✅ True |
| False | True | ✅ True |
| False | False | ❌ False |

---

# NOT Operator

Reverses the result.

```python
is_logged_in = False

print(not is_logged_in)
```

Output

```text
True
```

Example

```python
print(not True)
```

Output

```text
False
```

# Code Blocks

Python uses **indentation (spaces)** instead of braces `{}` to define blocks of code.

Correct

```python
if True:
    print("Inside the if block")
    print("Still inside the block")

print("Outside the block")
```

Output

```text
Inside the if block
Still inside the block
Outside the block
```

Incorrect

```python
if True:
print("Hello")
```

Output

```text
IndentationError
```

> **Tip:** By convention, Python uses **4 spaces** for indentation.

---

# Scope

Scope determines where a variable can be accessed.

---

## Global Scope

Variables created outside functions can be accessed throughout the program.

```python
name = "Python"

print(name)
```

Output

```text
Python
```

---

## Local Scope

Variables created inside a function are only available inside that function.

```python
def greet():
    message = "Hello"
    print(message)

greet()
```

Output

```text
Hello
```

Trying to access `message` outside the function will result in:

```text
NameError
```

# Common Beginner Mistakes

### ❌ Using `=` Instead of `==`

Incorrect

```python
if age = 18:
```

Correct

```python
if age == 18:
```

---

### ❌ Forgetting Indentation

Incorrect

```python
if True:
print("Hello")
```

Correct

```python
if True:
    print("Hello")
```

---

### ❌ Comparing Strings and Numbers

Incorrect

```python
age = "18"

if age > 17:
```

Output

```text
TypeError
```

Correct

```python
age = int(age)
```

## Truth Tables

### AND

```
True  and True   = True
True  and False  = False
False and True   = False
False and False  = False
```

### OR

```
True  or True    = True
True  or False   = True
False or True    = True
False or False   = False
```

### NOT

```
not True  = False
not False = True
```

---

# Summary

- `if` executes code when a condition is **True**.
- `else` executes when the condition is **False**.
- `elif` checks additional conditions.
- `and` requires **all** conditions to be **True**.
- `or` requires **at least one** condition to be **True**.
- `not` reverses a Boolean value.
- Python uses **indentation** (4 spaces) to define code blocks.
- Variables declared outside functions are **global**.
- Variables declared inside functions are **local**.
