# Python Project - Roller Coaster Ticket Calculator with Photo Option

This program demonstrates how to use:

- `if`, `elif`, and `else`
- Nested conditional statements
- Variables
- User input
- Arithmetic operations
- f-strings

The program:

1. Checks if the person is tall enough to ride.
2. Calculates the ticket price based on age.
3. Offers an optional ride photo for **£3**.
4. Displays the final bill.

---

# Ticket Prices

| Age | Ticket Price |
|------|-------------:|
| 18 years and above | £15 |
| 12–17 years | £10 |
| Below 12 years | £5 |

**Optional Ride Photo:** **£3**

**Minimum Height:** **120 cm**

---

# Python Program

```python
# Enter the height of the person.
# If height is 120 cm or more, they can ride.
# Calculate the ticket price based on age.
# Optionally add £3 for a ride photo.

height = float(input("What's your height? "))

total_bill = 0

if height >= 120:

    print("🎉 Yaay!! You can ride the game.")

    age = int(input("What is your age? "))

    if age >= 18:
        print("You need to pay £15 to ride the game.")
        total_bill += 15

    elif age >= 12:
        print("You need to pay £10 to ride the game.")
        total_bill += 10

    else:
        print("You need to pay £5 to ride the game.")
        total_bill += 5

    selection = input("Do you want to purchase a ride photo for £3? (Y/N): ")

    if selection.upper() == "Y":
        total_bill += 3

    print(f"Your total bill is £{total_bill}")

else:
    short_by = int(120 - height)
    print(f"Oops! You are short by {short_by} cm. Come back next year!")
```

# Python Shortcut Operators

Instead of writing

```python
total_bill = total_bill + 15
```

you can write

```python
total_bill += 15
```

Both statements are identical.

More examples

```python
x += 5
```

is the same as

```python
x = x + 5
```

# Tips for Beginners

- Initialise variables before using them.
- `elif` makes multiple conditions easier to read.
- `+=` is a shortcut for adding to a variable.
- Use `.upper()` to accept both uppercase and lowercase input.
- Use `f`-strings to display variables neatly.
- Keep user prompts clear and descriptive.

# Common Beginner Mistakes

### ❌ Forgetting to Initialise `total_bill`

Incorrect

```python
total_bill += 15
```

Output

```text
NameError
```

Correct

```python
total_bill = 0
```

---

### ❌ Checking Only Uppercase Input

Incorrect

```python
if selection == "Y":
```

If the user types **y**, nothing happens.

Better

```python
if selection.upper() == "Y":
```

---

### ❌ Using Separate `if` Statements

Incorrect

```python
if age >= 18:
    total_bill += 15

if age >= 12:
    total_bill += 10
```

A 20-year-old would be charged **£25**.

Use `elif` instead.
