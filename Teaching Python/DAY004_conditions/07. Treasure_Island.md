# Python Project - Treasure Island Game

This is a simple text-based adventure game that uses **nested `if` statements** to guide the player through different choices.

The player's mission is to find the hidden treasure by making the correct decisions.

---

# Game Rules

To win the game, the player must make the following choices:

1. Turn **Left (L)**.
2. Choose to **Wait (W)**.
3. Open the **Yellow (Y)** door.

Any other choice results in **GAME OVER**.

---

# Python Program

```python
print("🏝️ Welcome to Treasure Island")
print("Your mission is to find the treasure.")

selection = input("Do you want to turn Left (L) or Right (R)? ")

if selection.upper() == "R":
    print("💀 GAME OVER")

elif selection.upper() == "L":

    swim_or_wait = input("Do you want to Swim (S) or Wait (W)? ")

    if swim_or_wait.upper() == "S":
        print("💀 GAME OVER")

    else:

        door_choice = input("Choose a door: Red (R), Blue (B) or Yellow (Y): ")

        if door_choice.upper() == "R" or door_choice.upper() == "B":
            print("💀 GAME OVER")
        else:
            print("🎉 YOU HAVE WON!")
```

# Why Use `.upper()`?

Instead of checking only uppercase letters,

```python
if selection == "L":
```

use

```python
if selection.upper() == "L":
```

Now the user can enter

```
L
```

or

```
l
```

Both work correctly.

---

# Logical Operator Used

```python
if door_choice.upper() == "R" or door_choice.upper() == "B":
```

The `or` operator means:

- If either condition is **True**, the player loses.

Equivalent logic:

```
Door is Red?

OR

Door is Blue?
```

If either answer is **Yes**, print **GAME OVER**.

---

# Tips for Beginners

- Use nested `if` statements to create multiple levels of decision making.
- `.upper()` makes input case-insensitive.
- Use `or` when either condition can be true.
- Keep your indentation consistent (4 spaces).
- Give variables meaningful names like `door_choice` and `swim_or_wait`.

---

# Possible Improvement

Instead of using `else` for the winning door, check explicitly for **Yellow**.

Current version

```python
if door_choice.upper() == "R" or door_choice.upper() == "B":
    print("GAME OVER")
else:
    print("YOU HAVE WON!")
```

Improved version

```python
if door_choice.upper() == "Y":
    print("🎉 YOU HAVE WON!")
else:
    print("💀 GAME OVER")
```

This ensures that any unexpected input (such as `G` or `123`) also results in **GAME OVER**.
