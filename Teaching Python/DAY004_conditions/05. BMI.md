# Python Program - BMI Category Checker

This program calculates a person's **Body Mass Index (BMI)** and determines whether they are:

- Underweight
- Normal weight
- Overweight

---

# Python Program

```python
weight = 85
height = 1.85

bmi = weight / (height ** 2)

# 🚨 Do not modify the values above
# Write your code below 👇

if bmi < 18.5:
    print("You are underweight")
elif bmi >= 18.5 and bmi < 25:
    print("You are normal")
else:
    print("You are overweight")
```

---

# BMI Formula

```
BMI = Weight (kg)
      -----------
      Height² (m²)
```

or

```
BMI = Weight / (Height ** 2)
```

---

# Step-by-Step Calculation

Given

```python
weight = 85
height = 1.85
```

Calculate the square of the height

```
1.85 × 1.85

= 3.4225
```

Calculate BMI

```
85 ÷ 3.4225

= 24.84
```

Since

```
18.5 ≤ BMI < 25
```

Output

```text
You are normal
```

# Tips for Beginners

- `**` means **raise to the power**.
- `height ** 2` means **height × height**.
- `if` checks the first condition.
- `elif` checks another condition if the first one is false.
- `else` runs when none of the previous conditions are true.
- `and` means **both conditions must be true**.
- Conditions are checked from **top to bottom**.

---

# Common Beginner Mistakes

### ❌ Forgetting Parentheses

Incorrect

```python
bmi = weight / height ** 2
```

Although Python evaluates this correctly because `**` has higher precedence, writing it as below makes the formula clearer.

Preferred

```python
bmi = weight / (height ** 2)
```

---

### ❌ Using `=` Instead of `==`

Incorrect

```python
if bmi = 25:
```

Correct

```python
if bmi == 25:
```

---

### ❌ Using Separate `if` Statements

Incorrect

```python
if bmi < 18.5:
    print("Underweight")

if bmi < 25:
    print("Normal")
```

A BMI of **17** would print **both** messages.

Use `elif` instead.
