# Python Functions with and without Arguments

## Objective

Learn how to:

- Create a simple function.
- Call a function.
- Pass data to a function using **arguments (parameters)**.
- Reuse the same function with different values.

---

# Program

```python
# Function without arguments
def greet():
    print("Hello World")
    print("How are you?")

greet()


# Function with an argument
def greet_with_name(name):

    print(f"Hello {name}")
    print(f"How are you? {name}")
    print("Python is king")

greet_with_name("Sriram")
```

---

# Output

```
Hello World
How are you?

Hello Sriram
How are you? Sriram
Python is king
```

# Part 1 – Function Without Arguments

## Code

```python
def greet():
    print("Hello World")
    print("How are you?")
```

### Explanation

```python
def
```

Creates a function.

---

```python
greet
```

This is the **function name**.

---

```python
()
```

Empty parentheses mean the function **does not require any input**.

---

```python
:
```

The colon starts the function body.

---

The indented statements are executed whenever the function is called.

```python
print("Hello World")
print("How are you?")
```

---

## Calling the Function

```python
greet()
```

Output

```
Hello World
How are you?
```

> A function does nothing until it is called.

# Part 2 – Function with an Argument

## Code

```python
def greet_with_name(name):

    print(f"Hello {name}")
    print(f"How are you? {name}")
    print("Python is king")
```

---

## What is a Parameter?

```python
(name)
```

`name` is called a **parameter**.

A **parameter** is a variable that receives a value when the function is called.

---

## Calling the Function

```python
greet_with_name("Sriram")
```

Here,

```
"Sriram"
```

is called an **argument**.

Python stores this value inside the parameter `name`.

So inside the function:

```python
name = "Sriram"
```

---

## Output

```
Hello Sriram
How are you? Sriram
Python is king
```

---

# Understanding Parameters vs Arguments

```python
def greet_with_name(name):
```

`name` → **Parameter**

```python
greet_with_name("Sriram")
```

`"Sriram"` → **Argument**

Think of it like this:

```
Parameter → Placeholder

Argument → Actual Value
```

# Important Concepts

## Function

A reusable block of code.

Example

```python
def hello():
    print("Hello")
```

---

## Function Call

Executes the function.

```python
hello()
```

---

## Parameter

A variable defined in the function.

Example

```python
def greet(name):
```

`name` is the parameter.

---

## Argument

The value passed to the function.

Example

```python
greet("John")
```

`"John"` is the argument.

---

## f-Strings

Used to insert variables into a string.

Example

```python
name = "Alice"

print(f"Hello {name}")
```

Output

```
Hello Alice
```

---

# Real-World Example

```python
def welcome(employee):

    print(f"Welcome {employee}")
    print("Your account has been created.")

welcome("Sriram")
welcome("Priya")
welcome("Rahul")
```

Output

```
Welcome Sriram
Your account has been created.

Welcome Priya
Your account has been created.

Welcome Rahul
Your account has been created.
```

# Interview / Exam Questions

### Q1. What is a function?

A reusable block of code that performs a specific task.

---

### Q2. What keyword is used to define a function?

```python
def
```

---

### Q3. What is the difference between a parameter and an argument?

- **Parameter**: A variable in the function definition.
- **Argument**: The actual value passed when calling the function.

Example

```python
def greet(name):      # Parameter
    print(name)

greet("Sriram")       # Argument
```

---

### Q4. Can a function be called multiple times?

Yes.

Example

```python
greet()
greet()
greet()
```

---

### Q5. What is an f-string?

A formatted string that allows variables to be inserted directly into text.

Example

```python
name = "Python"

print(f"I love {name}")
```

Output

```
I love Python
```

---

# Summary

| Concept | Description | Example |
|---------|-------------|---------|
| `def` | Defines a function | `def greet():` |
| Function call | Executes a function | `greet()` |
| Parameter | Variable in a function definition | `def greet(name):` |
| Argument | Value passed to a function | `greet("Sriram")` |
| `print()` | Displays output | `print("Hello")` |
| f-string | Inserts variables into a string | `f"Hello {name}"` |

---

# Key Learning Points

- Functions help avoid repeating code.
- A function without parameters always performs the same task.
- Parameters allow a function to work with different input values.
- Arguments supply the actual data to the function.
- A single function can be reused many times with different arguments, making programs more flexible and maintainable.
