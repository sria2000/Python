# Python Project: Love Score Calculator

## Objective

Create a simple **Love Score Calculator** that:

- Takes two names as input.
- Combines both names.
- Counts the letters in the words **TRUE** and **LOVE**.
- Creates a love score by joining the two totals together.

> **Note:** This is a fun beginner project and is **not** based on any scientific calculation.

---

# Program

```python
def calculate_love_score(name1, name2):

    print(name1)
    print(name2)

    combined_names = (name1 + name2).lower()

    total_true = (
        combined_names.count('t') +
        combined_names.count('r') +
        combined_names.count('u') +
        combined_names.count('e')
    )

    total_love = (
        combined_names.count('l') +
        combined_names.count('o') +
        combined_names.count('v') +
        combined_names.count('e')
    )

    print(f"Love Score is {total_love}{total_true}")


calculate_love_score("Kanye West", "Kim Kardashian")
```

---

# Sample Output

```
Kanye West
Kim Kardashian

Love Score is 531
```

> The exact score depends on how many matching letters appear in the two names.

# Interview / Exam Questions

### Q1. Why is `.lower()` used?

To make the comparison **case-insensitive**, ensuring that uppercase and lowercase letters are treated the same.

---

### Q2. What does `.count()` do?

It returns the number of times a character appears in a string.

Example

```python
"hello".count("l")
```

Output

```
2
```

---

### Q3. What are `name1` and `name2`?

They are **parameters** of the function.

---

### Q4. What are `"Kanye West"` and `"Kim Kardashian"`?

They are **arguments** passed to the function.

---

### Q5. Is this line adding two numbers?

```python
print(f"{total_love}{total_true}")
```

No.

It joins the values together as text.

Example

```
LOVE = 5

TRUE = 31

Output = 531
```
