# Caesar Cipher – Python Encryption & Decryption

## 1. Overview

A **Caesar Cipher** is a simple encryption technique where each letter in the alphabet is shifted by a fixed number of positions.

For example, with a shift of `3`:

```text
a → d
b → e
c → f
...
x → a
y → b
z → c
```

The `% 26` operation ensures that the alphabet **wraps around** when we reach `z`.

---

# 2. Complete Program

```python
alphabets = [
    "a", "b", "c", "d", "e", "f", "g", "h", "i", "j",
    "k", "l", "m", "n", "o", "p", "q", "r", "s", "t",
    "u", "v", "w", "x", "y", "z"
]

text = input("Enter your text to encrypt: ")
shift = int(input("Enter the shift number: "))


def encrypt(original_text, shift_amount):

    cipher_text = ""

    for letter in original_text:
        shifted_location = (
            alphabets.index(letter) + shift_amount
        ) % 26

        cipher_text += alphabets[shifted_location]

    return cipher_text


def decrypt(original_text, shift_amount):

    decrypted_text = ""

    for letter in original_text:
        shifted_location = (
            alphabets.index(letter) - shift_amount
        ) % 26

        decrypted_text += alphabets[shifted_location]

    return decrypted_text


encrypted_text = encrypt(
    original_text=text,
    shift_amount=shift
)

print(f"Your encrypted text is: {encrypted_text}")


decrypted_text = decrypt(
    original_text=encrypted_text,
    shift_amount=shift
)

print(f"Your decrypted text is: {decrypted_text}")
```

# 4. How Encryption Works

The important line is:

```python
shifted_location = (alphabets.index(letter) + shift_amount) % 26
```

Suppose:

```text
letter = "h"
shift = 3
```

First, Python finds the position of `h`:

```python
alphabets.index("h")
```

Result:

```text
7
```

Then add the shift:

```text
7 + 3 = 10
```

Position `10` is:

```text
k
```

Therefore:

```text
h → k
```

---

# 5. Why `% 26` Is Important

There are 26 letters in the alphabet.

Consider:

```text
z + 3
```

The position of `z` is:

```text
25
```

So:

```text
25 + 3 = 28
```

But there is no position `28` in our list.

Using:

```python
28 % 26
```

gives:

```text
2
```

Position `2` is:

```text
c
```

Therefore:

```text
z + 3 → c
```

The `% 26` creates the **wrap-around**.

---

# 6. How Decryption Works

Encryption moves the alphabet **forward**:

```python
alphabets.index(letter) + shift_amount
```

Decryption moves the alphabet **backward**:

```python
alphabets.index(letter) - shift_amount
```

For example:

```text
Encrypted: khoor
Shift:     3
```

Decrypt:

```text
k → h
h → e
o → l
o → l
r → o
```

Result:

```text
hello
```


```python
encrypted_text = encrypt(

```

The return value from `encrypt()` is stored in:

```python

```

Then:

```python
decrypted_text = decrypt(
    original_text=encrypted_text,
    shift_amount=shift
)
```

The **encrypted text** is passed to `decrypt()`.

# 8. Important Python Concept – `return`

Inside `encrypt()`:

```python
return cipher_text
```

This sends the result back to the caller.

Therefore:

```python
encrypted_text = encrypt(...)
```

means:

```text
encrypt() produces a value
        ↓
return cipher_text
        ↓
encrypted_text receives the value
```

Similarly:

```python
return decrypted_text
```

allows:

```python
decrypted_text = decrypt(...)
```

to receive the decrypted result.

---

# 9. `print()` vs `return`

This is an important Python concept.

### `print()`

Displays something on the screen:

```python
print(cipher_text)
```

It does **not** give the value back to the calling code.

### `return`

Sends a value back:

```python
return cipher_text
```

So you can do:

```python
encrypted_text = encrypt(...)
```

### Remember

```text
print  → display
return → send value back
```

# 14. Key Interview / Practice Questions

## Q1. Why do we use `% 26`?

Because there are 26 letters in the alphabet and we need the alphabet to wrap around.

---

## Q2. Why does encryption use `+ shift`?

Because encryption moves the letter forward in the alphabet.

```python
index + shift_amount
```

---

## Q3. Why does decryption use `- shift`?

Because decryption reverses the encryption by moving the letter backward.

```python
index - shift_amount
```

---

## Q4. Why does `encrypt()` use `return`?

So that the encrypted value can be stored and used elsewhere:

```python
encrypted_text = encrypt(...)
```

---

## Q5. Why can't we decrypt `text` directly?

Because `text` is the **original unencrypted message**.

We need:

```python
decrypt(encrypted_text, shift)
```

not:

```python
decrypt(text, shift)
```

---

The current program will fail because the list contains only lowercase letters.



```python
text = text.lower()
```
