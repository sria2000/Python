# Python Function Arguments: Positional vs Keyword Arguments

## Objective

Learn the difference between:

- **Positional Arguments**
- **Keyword Arguments**

These are two ways of passing values to a function.

---

# 1. Positional Arguments

## Program

```python
def greet_with(name, location):
    print(f"Hello {name}, your location is {location}")

greet_with("Sri", "London")
```

---

## Output

```
Hello Sri, your location is London
```

---

# Step-by-Step Explanation

## Step 1: Define the Function

```python
def greet_with(name, location):
```

This function has **two parameters**:

- `name`
- `location`

---

## Step 2: Call the Function

```python
greet_with("Sri", "London")
```

Python assigns values based on their **position**.

```
First value  → name

Second value → location
```

So Python internally does:

```python
name = "Sri"

location = "London"
```

---

## Step 3: Print the Result

```python
print(f"Hello {name}, your location is {location}")
```

Output

```
Hello Sri, your location is London
```

---

# Why Are They Called Positional Arguments?

Because Python matches the values according to their position.

Example

```python
greet_with("Sri", "London")
```

```
Position 1 → name

Position 2 → location
```

---

# Incorrect Order

```python
greet_with("London", "Sri")
```

Python thinks:

```
name = "London"

location = "Sri"
```

Output

```
Hello London, your location is Sri
```

The program runs successfully, but the output is incorrect because the arguments were passed in the wrong order.

---

# 2. Keyword Arguments

## Program

```python
def try_keyword(name, age, location):
    print(f"Hello {name}, your age is {age}, and your location is {location}")

try_keyword(age=50, name="Sri", location="London")
```

---

## Output

```
Hello Sri, your age is 50, and your location is London
```

---

# Step-by-Step Explanation

## Function Definition

```python
def try_keyword(name, age, location):
```

This function has three parameters:

- `name`
- `age`
- `location`

---

## Function Call

```python
try_keyword(age=50, name="Sri", location="London")
```

Each value is assigned using its parameter name.

Python internally matches:

```
name = "Sri"

age = 50

location = "London"
```

The order does **not** matter.

---

# Changing the Order

The following calls all produce the same output.

Example 1

```python
try_keyword(name="Sri", age=50, location="London")
```

Example 2

```python
try_keyword(location="London", name="Sri", age=50)
```

Example 3

```python
try_keyword(age=50, location="London", name="Sri")
```

Output

```
Hello Sri, your age is 50, and your location is London
```

# Dry Run

## Positional Arguments

```python
greet_with("Sri", "London")
```

| Position | Parameter | Value |
|---------:|-----------|-------|
| 1 | `name` | `"Sri"` |
| 2 | `location` | `"London"` |

Output

```
Hello Sri, your location is London
```

---

## Keyword Arguments

```python
try_keyword(age=50, name="Sri", location="London")
```

| Keyword | Parameter | Value |
|---------|-----------|-------|
| `age=50` | `age` | `50` |
| `name="Sri"` | `name` | `"Sri"` |
| `location="London"` | `location` | `"London"` |

Output

```
Hello Sri, your age is 50, and your location is London
```

---

# Positional vs Keyword Arguments

| Positional Arguments | Keyword Arguments |
|----------------------|-------------------|
| Values are matched by **position** | Values are matched by **parameter name** |
| Order is important | Order is not important |
| Easier for short functions | More readable for many parameters |
| Wrong order can produce incorrect output | Less chance of assigning values incorrectly |

---

# Mixing Positional and Keyword Arguments

Python allows both styles together.

Example

```python
def student(name, age, city):
    print(name, age, city)

student("Sri", age=50, city="London")
```

Output

```
Sri 50 London
```

> **Rule:** Positional arguments must come **before** keyword arguments.

Correct

```python
student("Sri", age=50, city="London")
```

Incorrect

```python
student(age=50, "Sri", city="London")
```

This results in a **SyntaxError**.

# Interview / Exam Questions

### Q1. What are positional arguments?

Arguments that are assigned to parameters based on their position in the function call.

---

### Q2. What are keyword arguments?

Arguments passed using the parameter names, allowing them to be supplied in any order.

---

### Q3. Which type of argument requires the correct order?

**Positional arguments.**

---

### Q4. Which type of argument is easier to read when there are many parameters?

**Keyword arguments.**

---

### Q5. Can positional and keyword arguments be used together?

Yes, but positional arguments must come first.

Example

```python
student("Sri", age=50, city="London")
```

---

# Summary

| Concept | Description | Example |
|---------|-------------|---------|
| Positional argument | Values matched by position | `greet_with("Sri", "London")` |
| Keyword argument | Values matched by parameter name | `try_keyword(age=50, name="Sri", location="London")` |
| Parameter | Variable in the function definition | `name`, `age`, `location` |
| Argument | Actual value passed to the function | `"Sri"`, `50`, `"London"` |

---

# Key Learning Points

- **Positional arguments** depend on the order in which values are passed.
- **Keyword arguments** explicitly specify which parameter each value belongs to, making code clearer and more flexible.
- Keyword arguments are especially useful for functions with many parameters because they improve readability and reduce the chance of passing values in the wrong order.
