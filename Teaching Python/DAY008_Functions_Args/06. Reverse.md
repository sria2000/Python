# Python String Reversal Using Slicing

## 1. Overview

Python provides a simple way to reverse a string using **string slicing**.

The syntax is:

```python
string[start:stop:step]
```

To reverse a string, we use:

```python
string[::-1]
```

The `-1` tells Python to move through the string **backwards**.

---

# 2. Complete Program

```python
input_string = input("Enter your input to reverse :")

new_string = input_string[::-1]

print(new_string)
```

# 4. Understanding `[::-1]`

The general slicing syntax is:

```python
string[start:stop:step]
```

For example:

```python
text[::1]
```

means:

```text
Start from the beginning
Go to the end
Move forward by 1
```

Whereas:

```python
text[::-1]
```

means:

```text
Start from the end
Go backwards
Move by 1 position
```

Therefore:

```python
input_string[::-1]
```

reverses the entire string.

---

# 5. Breaking Down the Syntax

Consider:

```python
input_string[::-1]
```

There are three slicing components:

```text
[start : stop : step]
```

Our code is:

```text
[     :     : -1]
```

### Start

```text
empty
```

Python uses the appropriate starting position based on the negative step.

### Stop

```text
empty
```

Python continues through the entire string.

### Step

```text
-1
```

Move one character backwards at a time.

---

# 6. Example With Character Positions

Consider:

```python
text = "hello"
```

The positions are:

```text
Character:  h   e   l   l   o
Index:      0   1   2   3   4
```

Normal slicing:

```python
text[::1]
```

gives:

```text
hello
```

Reverse slicing:

```python
text[::-1]
```

gives:

```text
olleh
```

Python effectively reads:

```text
4 → 3 → 2 → 1 → 0
```

which means:

```text
o → l → l → e → h
```

---

# 7. Why Do We Use `-1`?

The `step` determines the direction.

### Positive step

```python
text[::1]
```

Moves forward:

```text
→ → → →
```

### Negative step

```python
text[::-1]
```

Moves backward:

```text
← ← ← ←
```

Therefore:

```python
[::-1]
```

is a common Python idiom for reversing a sequence.

---

# 8. Important Python Concept – Strings Are Immutable

Python strings cannot be changed directly.

For example:

```python
text = "hello"
```

You cannot modify an individual character like:

```python
text[0] = "H"
```

This produces an error.

Instead, operations such as slicing create a **new string**:

```python
new_string = text[::-1]
```

So:

```text
Original string
      ↓
   "hello"
      ↓
   [::-1]
      ↓
   "olleh"
```

The original `input_string` remains unchanged.

---

# 9. Alternative Method Using a Loop

You can also reverse a string using a `for` loop:

```python
input_string = input("Enter your input to reverse: ")

new_string = ""

for letter in input_string:
    new_string = letter + new_string

print(new_string)
```

For:

```text
hello
```

the loop builds:

```text
h
eh
leh
lleh
olleh
```

However, the slicing approach is much simpler:

```python
new_string = input_string[::-1]
```

---

# 10. Alternative Using `reversed()`

Python also provides the `reversed()` function:

```python
input_string = input("Enter your input to reverse: ")

new_string = "".join(reversed(input_string))

print(new_string)
```

`reversed()` returns the characters in reverse order, and:

```python
"".join(...)
```

joins them back together into a string.

---

# 11. Comparison

| Method       | Example                   | Difficulty        |
| ------------ | ------------------------- | ----------------- |
| Slicing      | `text[::-1]`              | Very easy         |
| `reversed()` | `"".join(reversed(text))` | Easy              |
| `for` loop   | Build string manually     | Beginner practice |

For normal Python code, the simplest solution is:

```python
new_string = input_string[::-1]
```

# 12. Interview Questions

## Q1. How do you reverse a string in Python?

Using slicing:

```python
text[::-1]
```

---

## Q2. What does `[::-1]` mean?

It means slice the entire string with a step of `-1`, causing Python to traverse the string backwards.

---

## Q3. What is the general syntax for slicing?

```python
sequence[start:stop:step]
```

---

## Q4. What does the `step` parameter do?

It determines how many positions Python moves each time and can also determine the direction.

```python
text[::1]    # Forward
text[::-1]   # Backward
```

---

## Q5. Does `[::-1]` modify the original string?

No.

Strings are immutable, so a new reversed string is created.

---

## Q6. What is the easiest way to reverse a string in Python?

```python
text[::-1]
```
