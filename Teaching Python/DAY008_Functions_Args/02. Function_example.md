# Python Function Example: Life Left in Weeks

## Objective

Create a function that calculates **how many weeks are left until the age of 90**.

This example demonstrates:

- Functions with and without parameters
- Mathematical calculations
- Passing arguments to a function
- Using variables inside a function

---

# Version 1 – Function Using User Input

## Program

```python
def life_left_weeks():

    current_age = int(input("What is your current age? "))
    top_age = 90
    weeks_in_year = 52

    balance_years = top_age - current_age
    balance_weeks = weeks_in_year * balance_years

    print(f"You have {balance_weeks} weeks left")

life_left_weeks()
```

---

## Sample Output

```
What is your current age? 25

You have 3380 weeks left
```

### Calculation

```
Top age      = 90

Current age  = 25

Years left   = 90 - 25 = 65

Weeks left   = 65 × 52 = 3380
```

---

# Version 2 – Function Using a Parameter

## Program

```python
def life_in_weeks(age):

    top_age = 90
    weeks_in_year = 52

    balance_years = top_age - age
    balance_weeks = weeks_in_year * balance_years

    print(f"You have {balance_weeks} weeks left")

life_in_weeks(12)
```

---

## Output

```
You have 4056 weeks left
```

### Calculation

```
90 - 12 = 78 years

78 × 52 = 4056 weeks
```

---

# Step-by-Step Explanation

## Step 1: Define the Function

```python
def life_in_weeks(age):
```

- `def` creates a function.
- `life_in_weeks` is the function name.
- `age` is a **parameter** that receives a value when the function is called.

---

## Step 2: Store the Maximum Age

```python
top_age = 90
```

The program assumes an average lifespan of **90 years**.

---

## Step 3: Store Weeks in One Year

```python
weeks_in_year = 52
```

There are approximately **52 weeks in a year**.

---

## Step 4: Calculate Remaining Years

```python
balance_years = top_age - age
```

Example

```
Age = 12

90 - 12 = 78
```

---

## Step 5: Calculate Remaining Weeks

```python
balance_weeks = weeks_in_year * balance_years
```

Example

```
78 × 52 = 4056
```

---

## Step 6: Display the Result

```python
print(f"You have {balance_weeks} weeks left")
```

Output

```
You have 4056 weeks left
```

---

## Step 7: Call the Function

```python
life_in_weeks(12)
```

The value `12` is passed as the argument.

Inside the function:

```python
age = 12
```

---

# Difference Between the Two Versions

| Version 1 | Version 2 |
|-----------|-----------|
| Uses `input()` to ask the user for their age | Receives the age as a parameter |
| Interactive | Can be called directly with any value |
| Less reusable | More reusable and easier to test |
| Depends on user input | Works with any supplied argument |

# Important Concepts

## Function

A reusable block of code.

```python
def hello():
    print("Hello")
```

---

## Parameter

A variable that receives data.

```python
def life_in_weeks(age):
```

Here, `age` is the parameter.

---

## Argument

The value passed when calling a function.

```python
life_in_weeks(12)
```

Here, `12` is the argument.

---

## Variables

```python
top_age = 90
weeks_in_year = 52
```

Variables store values for later use.

---

## Arithmetic Operators

Subtraction

```python
90 - age
```

Multiplication

```python
52 * balance_years
```

---

## f-String

```python
print(f"You have {balance_weeks} weeks left")
```

An f-string inserts variable values directly into a string.

# Real-World Example

```python
def years_until_retirement(age):

    retirement_age = 65
    years_left = retirement_age - age

    print(f"You have {years_left} years until retirement.")

years_until_retirement(40)
```

Output

```
You have 25 years until retirement.
```

# Key Learning Points

- Functions become more flexible when they accept **parameters**.
- A parameter allows the same function to work with different input values.
- Using parameters is better than relying on `input()` because the function is easier to reuse, test, and integrate into larger programs.
- This example demonstrates how to combine functions, variables, arithmetic operations, and formatted output to solve a simple real-world problem.
