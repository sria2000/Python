# Python Dictionary – Creating and Adding Key/Value Pairs

## 1. Objective

This program demonstrates how to:

* Create an empty dictionary
* Add key/value pairs to a dictionary
* Print the dictionary after each addition
* Understand that dictionaries can be populated dynamically

---

# 2. Complete Program

```python
empty_dictionary = {}

empty_dictionary["Name"] = "Edison"
print(empty_dictionary)

empty_dictionary["Discovered"] = "Bulb"
print(empty_dictionary)

empty_dictionary["Country"] = "America"
print(empty_dictionary)
```

---

# 3. Creating an Empty Dictionary

An empty dictionary can be created using:

```python
empty_dictionary = {}
```

At this point, the dictionary contains nothing:

```text
{}
```

You can also create an empty dictionary using:

```python
empty_dictionary = dict()
```

Both are valid:

```python
{}
```

and:

```python
dict()
```

---

# 4. Adding the First Key/Value Pair

This statement:

```python
empty_dictionary["Name"] = "Edison"
```

adds:

```text
Name → Edison
```

The dictionary becomes:

```python
{
    "Name": "Edison"
}
```

Output:

```text
{'Name': 'Edison'}
```

---

# 5. Adding Another Key/Value Pair

Next:

```python
empty_dictionary["Discovered"] = "Bulb"
```

adds another key/value pair.

The dictionary becomes:

```python
{
    "Name": "Edison",
    "Discovered": "Bulb"
}
```

Output:

```text
{'Name': 'Edison', 'Discovered': 'Bulb'}
```

---

# 6. Adding the Third Key/Value Pair

Finally:

```python
empty_dictionary["Country"] = "America"
```

adds:

```text
Country → America
```

The final dictionary becomes:

```python
{
    "Name": "Edison",
    "Discovered": "Bulb",
    "Country": "America"
}
```

Output:

```text
{'Name': 'Edison', 'Discovered': 'Bulb', 'Country': 'America'}
```

---

# 7. Program Flow

The dictionary is built progressively:

```text
Start
  ↓
{}
  ↓
Add Name
  ↓
{'Name': 'Edison'}
  ↓
Add Discovered
  ↓
{'Name': 'Edison', 'Discovered': 'Bulb'}
  ↓
Add Country
  ↓
{'Name': 'Edison', 'Discovered': 'Bulb', 'Country': 'America'}
```

---

# 8. Important Syntax

The general syntax for adding an item is:

```python
dictionary["key"] = "value"
```

For example:

```python
empty_dictionary["Name"] = "Edison"
```

Here:

```text
"Name"   → Key
"Edison" → Value
```

---

# 9. Adding vs Updating

The same syntax is used to **add** and **update** dictionary values.

### Adding a new key

If the key doesn't exist:

```python
empty_dictionary["Country"] = "America"
```

Python adds it.

### Updating an existing key

If the key already exists:

```python
empty_dictionary["Country"] = "UK"
```

Python changes the value.

For example:

```python
empty_dictionary["Country"] = "America"

empty_dictionary["Country"] = "UK"

print(empty_dictionary)
```

Output:

```text
{'Country': 'UK'}
```

The dictionary doesn't contain two `Country` entries.

---

# 10. Dictionary Keys Must Be Unique

A dictionary cannot have duplicate keys.

For example:

```python
dictionary = {
    "Name": "Edison",
    "Name": "Tesla"
}
```

The second `"Name"` replaces the first one.

The result is:

```text
{'Name': 'Tesla'}
```

Therefore:

```text
One key → One value
```

---

# 11. Empty Dictionary vs Empty List

Be careful with the syntax.

### Empty dictionary

```python
empty_dictionary = {}
```

### Empty list

```python
empty_list = []
```

The difference is:

```text
{} → Dictionary
[] → List
```

# 12. Useful Interview Question

## Q: How do you create an empty dictionary in Python?

Two common ways:

```python
dictionary = {}
```

or:

```python
dictionary = dict()
```

The `{}` syntax is the most commonly used.

---

## Q: How do you add a key/value pair?

```python
dictionary["key"] = "value"
```

Example:

```python
dictionary["Name"] = "Edison"
```

---

## Q: What happens if the key already exists?

The existing value is **updated**.

```python
dictionary["Country"] = "America"
dictionary["Country"] = "UK"
```

Final value:

```text
Country → UK
```

# 13. Expected Output

Running your program produces:

```text
{'Name': 'Edison'}
{'Name': 'Edison', 'Discovered': 'Bulb'}
{'Name': 'Edison', 'Discovered': 'Bulb', 'Country': 'America'}
```

# 14. Key Takeaways

```text
1. {} creates an empty dictionary.

2. dictionary["key"] = "value"
   adds a new key/value pair.

3. The same syntax updates an existing key.

4. Dictionary keys must be unique.

5. A dictionary grows dynamically as new keys are added.

6. {} is a dictionary, while [] is a list.

7. dict() can also be used to create an empty dictionary.
```

```python
dictionary = {}
```
