# Grading Program – Python Dictionary

## 1. Question

You have access to a database of `student_scores` in the format of a Python dictionary.

The **keys** in `student_scores` are the names of the students, and the **values** are their exam scores.

Write a program that **converts their scores to grades**.

By the end of the program, create a new dictionary called `student_grades` containing:

* Student names as **keys**
* Their assessed grades as **values**

The final `student_grades` dictionary will be checked by an automated test.

> **Important:** Do not modify the existing `student_scores` dictionary.

### Grading Criteria

|       Score | Grade                  |
| ----------: | ---------------------- |
|      91–100 | `Outstanding`          |
|       81–90 | `Exceeds Expectations` |
|       71–80 | `Acceptable`           |
| 70 or lower | `Fail`                 |

---

# 2. Given `student_scores`

```python
student_scores = {
    'Harry': 88,
    'Ron': 78,
    'Hermione': 95,
    'Draco': 75,
    'Neville': 60
}
```

---

# 3. Solution

```python
student_scores = {
    'Harry': 88,
    'Ron': 78,
    'Hermione': 95,
    'Draco': 75,
    'Neville': 60
}

student_grades = {}

for name, score in student_scores.items():

    if score > 90:
        student_grades[name] = "Outstanding"

    elif score > 80:
        student_grades[name] = "Exceeds Expectations"

    elif score > 70:
        student_grades[name] = "Acceptable"

    else:
        student_grades[name] = "Fail"

print(student_grades)
```

# 5. Step-by-Step Explanation

## Step 1 – Create an Empty Dictionary

```python

```

We create an empty dictionary to store the final results.

Initially:

```text
{}
```

## Step 2 – Loop Through the Dictionary

```python
for name, score in student_scores.items():
```

`.items()` gives us both the **key** and the **value**.

For example:

```text
Name       Score
----------------
Harry      88
Ron        78
Hermione   95
Draco      75
Neville    60
```

The loop assigns:

```text
name  → Student name
score → Student score
```

For the first iteration:

```text
name = "Harry"
score = 88
```

# 6. Convert Score to Grade

For Harry:

```python
if score > 90:
```

`88 > 90` is:

```text
False
```

Next:

```python
elif score > 80:
```

`88 > 80` is:

```text
True
```

Therefore:

```python
student_grades[name] = "Exceeds Expectations"
```

becomes:

```python
student_grades["Harry"] = "Exceeds Expectations"
```

The dictionary now contains:

```python
{
    "Harry": "Exceeds Expectations"
}
```

# 7. Why We Use `score` Instead of `student_scores[score]`

Inside:

```python
for name, score in student_scores.items():
```

Python already gives us the key and value.

For example:

```text
name  = "Harry"
score = 88
```

Therefore we use:

```python
if score > 90:
```

Not:

```python
if student_scores[score] > 90:
```

The latter would try to find:

```python
student_scores[88]
```

But `88` is not a key.

The keys are:

```text
Harry
Ron
Hermione
Draco
Neville
```

---

# 8. Why `else` Is Better Than `elif score < 70`

The original code used:

```python
elif score < 70:
    student_grades[name] = "Fail"
```

There is a small problem.

The requirement says:

```text
70 or lower = Fail
```

But:

```python
score < 70
```

does **not include 70**.

For example:

```python
score = 70
```

would not match:

```python
score < 70
```

Using:

```python
else:
    student_grades[name] = "Fail"
```

is better.

Why?

Because all scores that didn't match the previous conditions are automatically `70 or lower`.

---

# 9. Understanding the Conditions

The conditions are deliberately written in descending order:

```python
if score > 90:
```

This covers:

```text
91–100
```

Then:

```python
elif score > 80:
```

Because the previous condition already failed, this covers:

```text
81–90
```

Then:

```python
elif score > 70:
```

This covers:

```text
71–80
```

Finally:

```python
else:
```

covers:

```text
70 or lower
```

So the logic is:

```text
91–100
   ↓
Outstanding

81–90
   ↓
Exceeds Expectations

71–80
   ↓
Acceptable

70 or below
   ↓
Fail
```

# 11. Important Dictionary Concept

This line:

```python
student_grades[name] = "Outstanding"
```

uses the student's name as the **key**.

For example:

```python
student_grades["Hermione"] = "Outstanding"
```

The resulting dictionary contains:

```text
Key       → Value
-----------------------------
Hermione  → Outstanding
```

So the final structure is:

```text
Student Name → Grade
```

---

# 12. Important Automated Test Lesson

The automated test checks the actual contents of:

```python
student_grades
```

It does **not** just check what you print.

Therefore, this alone would not be sufficient:

```python
print(f"{name} is Outstanding")
```

You need:

```python
student_grades[name] = "Outstanding"
```

The test may also require the **exact spelling** of the grade.

For example:

```text
"Exceeds Expectation"   ❌
"Exceeds Expectations"  ✅
```

Even a small difference can cause the test to fail.
