# Python Nested Dictionary – Simple Example

## 1. What is a Nested Dictionary?

A **nested dictionary** is a dictionary that contains another dictionary as one of its values.

In this example:

```python
student = {
    "Name": "Ram",
    "Age": 25,
    "Address": {
        "City": "London",
        "Country": "UK"
    }
}
```

The `"Address"` key contains another dictionary:

```python
{
    "City": "London",
    "Country": "UK"
}
```

---

# 2. Complete Program

```python
student = {
    "Name": "Ram",
    "Age": 25,
    "Address": {
        "City": "London",
        "Country": "UK"
    }
}

print(student["Name"])

print(student["Address"])

print(student["Address"]["City"])
print(student["Address"]["Country"])
```

---

# 3. Dictionary Structure

The structure looks like this:

```text
student
│
├── Name → Ram
│
├── Age → 25
│
└── Address
    │
    ├── City → London
    │
    └── Country → UK
```

The outer dictionary is:

```python
student
```

The nested dictionary is:

```python
student["Address"]
```

---

# 4. Accessing the Name

```python
print(student["Name"])
```

Output:

```text
Ram
```

Here, `"Name"` is a key in the **outer dictionary**.

---

# 5. Accessing the Address

```python
print(student["Address"])
```

Output:

```text
{'City': 'London', 'Country': 'UK'}
```

The value of `"Address"` is itself a dictionary.

---

# 6. Accessing the City

To access `"City"`:

```python
print(student["Address"]["City"])
```

Output:

```text
London
```

Python performs two lookups:

```text
student
   ↓
"Address"
   ↓
{"City": "London", "Country": "UK"}
   ↓
"City"
   ↓
London
```

---

# 7. Accessing the Country

```python
print(student["Address"]["Country"])
```

Output:

```text
UK
```

Again, there are two levels:

```text
student
   ↓
Address
   ↓
Country
   ↓
UK
```

---

# 8. Expected Output

Running the complete program produces:

```text
Ram
{'City': 'London', 'Country': 'UK'}
London
UK
```

---

# 9. Key Concept

The general pattern for accessing a nested dictionary is:

```python
outer_dictionary["outer_key"]["inner_key"]
```

For this example:

```python
student["Address"]["City"]
```

means:

```text
student
  → Address
      → City
          → London
```

---

# 10. Adding Another Nested Field

You can also add data to the nested dictionary:

```python
student["Address"]["Postcode"] = "AB12 3CD"
```

Now:

```python
print(student["Address"])
```

will show:

```text
{'City': 'London', 'Country': 'UK', 'Postcode': 'AB12 3CD'}
```

---

# 11. Updating a Nested Value

You can update the nested value in exactly the same way:

```python
student["Address"]["City"] = "Manchester"
```

Now:

```python
print(student["Address"]["City"])
```

outputs:

```text
Manchester
```

---

# 12. Key Takeaways

```text
1. A dictionary can contain another dictionary.

2. This is called a nested dictionary.

3. The nested dictionary is stored as a value
   of an outer dictionary key.

4. Access one level:
   student["Address"]

5. Access two levels:
   student["Address"]["City"]

6. Add nested data:
   student["Address"]["Postcode"] = "AB12 3CD"

7. Update nested data:
   student["Address"]["City"] = "Manchester"
```

## Core Pattern

```python
student = {

        "City": "London",

    }

```

### Remember

```text
Dictionary inside Dictionary
          ↓
   Nested Dictionary
          ↓
dict["key"]["key"]
```
