Write a Python program to understand and test basic **dictionary operations**.

# 3. Dictionary Structure

A Python dictionary stores data as **key/value pairs**.

General syntax:

```python
dictionary = {
    "key1": "value1",
    "key2": "value2"
}
```

In this example:

```python
dictionary_testing = {
    "Name": "Sriram",
    "Age": 25,
    "Address": "...",
    "Contact": "001 1234567",
    "123": "Random"
}
```

The structure is:

```text
Key       → Value
-----------------------------
Name      → Sriram
Age       → 25
Address   → 123, Moon Island...
Contact   → 001 1234567
123       → Random
```

---

# 4. Accessing Dictionary Values

Values are accessed using their keys.

For example:

```python
print(dictionary_testing["Name"])
```

Output:

```text
Sriram
```

Similarly:

```python
print(dictionary_testing["Age"])
```

Output:

```text
25
```

---

# 5. Accessing Different Data Types

Dictionary values can contain different data types.

For example:

```python
"Name": "Sriram"
```

The value is a string.

```python
"Age": 25
```

The value is an integer.

Therefore a dictionary does not require all values to have the same data type.

---

# 6. String `"123"` as a Dictionary Key

This is valid:

```python
"123": "Random"
```

Here `"123"` is a **string**, not an integer.

Therefore:

```python
dictionary_testing["123"]
```

works and returns:

```text
Random
```

But this is a different key:

```python
dictionary_testing[123]
```

because:

```text
"123" ≠ 123
```

The first is a string, while the second is an integer.

---

# 7. Dictionary Keys Are Case-Sensitive

The dictionary contains:

```python
"Contact": "001 1234567"
```

Therefore this works:

```python
print(dictionary_testing["Contact"])
```

But this does not:

```python
print(dictionary_testing["contact"])
```

because:

```text
"Contact" ≠ "contact"
```

Python dictionary keys are **case-sensitive**.

---

# 8. Understanding `KeyError`

If you uncomment:

```python
print(dictionary_testing["contact"])
```

Python will generate:

```text
KeyError: 'contact'
```

This happens because `"contact"` does not exist as a key.

The dictionary contains:

```python
"Contact"
```

not:

```python
"contact"
```


adds a new key/value pair.

Before:

```text
Name
Age
Address
Contact
123
```

After:

```text
Name
Age
Address
Contact
123

```

The dictionary now contains:

```python

```

---

# 10. Adding vs Updating

This syntax has two possible behaviours:

```python
dictionary_testing["Country"] = "Antarctica"
```

### If the key does not exist

Python **creates** the key:

```text
Country → Antarctica
```

### If the key already exists

Python **updates** its value.

For example:

```python
dictionary_testing["Country"] = "UK"
```

If `Country` already exists, its value changes from:

```text
Antarctica
```

to:

```text
UK
```

Therefore:

```python
dictionary[key] = value
```

can mean either **add** or **update**.

# 14. Useful Dictionary Methods

Python provides several useful dictionary methods.

### `keys()`

Returns all keys:

```python
print(dictionary_testing.keys())
```

### `values()`

Returns all values:

```python
print(dictionary_testing.values())
```

### `items()`

Returns key/value pairs:

```python
print(dictionary_testing.items())
```

### `get()`

Safely retrieves a value:

```python
print(dictionary_testing.get("Name"))
```

Unlike:

```python
dictionary_testing["contact"]
```

`get()` does not raise a `KeyError` if the key doesn't exist.

For example:

```python
print(dictionary_testing.get("contact"))
```

returns:

```text
None
```

You can also provide a default value:

```python
print(dictionary_testing.get("contact", "Key not found"))
```

Output:

```text
Key not found
```

# 15. Dictionary vs List

| Feature        | Dictionary      | List      |
| -------------- | --------------- | --------- |
| Stores         | Key/value pairs | Values    |
| Access         | By key          | By index  |
| Example        | `dict["Name"]`  | `list[0]` |
| Keys           | Yes             | No        |
| Ordered        | Yes             | Yes       |
| Duplicate keys | Not allowed     | N/A       |

Example:

```python
person = {
    "Name": "Sriram",
    "Age": 25
}
```

Access using:

```python
person["Name"]
```

A list would use:

```python
person = ["Sriram", 25]
```

and access:

```python
person[0]
```

# 16. Interview Questions

## Q1. What is a dictionary in Python?

A dictionary is a collection of **key/value pairs**.

```python
person = {
    "Name": "Sriram",
    "Age": 25
}
```

---

## Q2. How do you access a dictionary value?

Using its key:

```python
person["Name"]
```

---

## Q3. Are dictionary keys case-sensitive?

Yes.

```text
"Name" ≠ "name"
```

---

## Q4. What happens when you access a non-existent key using `dict[key]`?

Python raises a:

```text
KeyError
```

---

## Q5. How can you safely access a key that might not exist?

Use:

```python
dictionary.get("key")
```

For example:

```python
dictionary_testing.get("contact")
```

---

## Q6. How do you add a new item to a dictionary?

```python
dictionary["Country"] = "UK"
```

---

## Q7. How do you update an existing dictionary value?

Use the same syntax:

```python
dictionary["Age"] = 26
```

---

## Q8. Can a dictionary contain different data types?

Yes.

For example:

```python
person = {
    "Name": "Sriram",      # string
    "Age": 25,             # integer
    "Active": True         # boolean
}
```

---

## Q9. Can `"123"` be a dictionary key?

Yes.

```python
dictionary = {
    "123": "Random"
}
```

But `"123"` and `123` are different keys.

# 17. Key Takeaways

```text
1. Dictionary = key/value pairs.

2. Access values using:
   dictionary["key"]

3. Dictionary keys are case-sensitive.

4. A missing key accessed with [] raises KeyError.

5. Use .get() when a key might not exist.

6. dictionary[key] = value adds a new key
   if it doesn't already exist.

7. dictionary[key] = value updates the value
   if the key already exists.

8. Keys must be unique.

9. Values can have different data types.

10. "123" and 123 are different dictionary keys.
```
