# Python Dictionary – Adding, Updating and Storing Multiple Records

## 1. Objective

This exercise demonstrates:

* Creating an empty dictionary
* Adding a key/value pair
* Updating an existing key
* Understanding why dictionary values are replaced
* Storing multiple people using nested dictionaries
* Understanding when to use a dictionary vs multiple dictionaries

---

# 2. Adding and Updating a Dictionary Value

## Example

```python
empty_dictionary = {}

empty_dictionary["Name"] = "Edison"
print(empty_dictionary)

empty_dictionary["Name"] = "Einstein"
print(empty_dictionary)

empty_dictionary["Name"] = "Newton"
print(empty_dictionary)
```

### Output

```text
{'Name': 'Edison'}
{'Name': 'Einstein'}
{'Name': 'Newton'}
```

---

# 3. Why Does the Value Get Replaced?

A dictionary stores data using:

```text
KEY → VALUE
```

Initially:

```python
empty_dictionary["Name"] = "Edison"
```

The dictionary becomes:

```text
Name → Edison
```

Then:

```python
empty_dictionary["Name"] = "Einstein"
```

Python sees that `"Name"` already exists.

Therefore it **updates the existing value**:

```text
Name → Edison
       ↓
Name → Einstein
```

Then:

```python
empty_dictionary["Name"] = "Newton"
```

updates it again:

```text
Name → Einstein
       ↓
Name → Newton
```

The final dictionary contains only:

```text
Name → Newton
```

---

# 4. Important Rule

Dictionary keys must be **unique**.

You cannot have:

```text
Name → Edison
Name → Einstein
Name → Newton
```

inside the same dictionary using the same `"Name"` key.

Instead, assigning the same key again **replaces the existing value**.

```python
dictionary["Name"] = "Edison"
dictionary["Name"] = "Einstein"
```

Result:

```python
{'Name': 'Einstein'}
```

---

# 5. Adding Another Field

Suppose we want to store:

```text
Name
Age
```

We can do:

```python
new_empty_dictionary = {}

new_empty_dictionary["Name"] = "Ram"
new_empty_dictionary["Age"] = 25
```

At this point:

```python
{
    "Name": "Ram",
    "Age": 25
}
```

---

# 6. What Happens If We Add Another Person?

Now consider:

```python
new_empty_dictionary["Name"] = "Sri"
new_empty_dictionary["Age"] = 26
```

The output is:

```text
{'Name': 'Sri', 'Age': 26}
```

### Why?

Because `"Name"` already exists:

```text
Name → Ram
```

and:

```python
new_empty_dictionary["Name"] = "Sri"
```

changes it to:

```text
Name → Sri
```

Similarly:

```text
Age → 25
```

becomes:

```text
Age → 26
```

### Important Note

The above code **replaces Ram with Sri**.

It does not create two people.

---

# 7. Why Can't We Store Both People This Way?

This structure:

```python
{
    "Name": "Ram",
    "Age": 25
}
```

represents **one person**.

If you do:

```python
dictionary["Name"] = "Sri"
```

you're updating that person's name.

You are not creating a second person.

To store multiple people, we need another level of structure.

---

# 8. Using Nested Dictionaries

We can create a dictionary containing multiple dictionaries:

```python
latest_dictionary = {}

latest_dictionary["Person1"] = {
    "Name": "Arjun",
    "Age": 25,
}

latest_dictionary["Person2"] = {
    "Name": "Nakul",
    "Age": 26,
}

print(latest_dictionary)
```

---

# 9. Structure of the Nested Dictionary

The resulting structure is:

```text
latest_dictionary
│
├── Person1
│   ├── Name → Arjun
│   └── Age  → 25
│
└── Person2
    ├── Name → Nakul
    └── Age  → 26
```

The dictionary contains two keys:

```text
Person1
Person2
```

Each key contains another dictionary.

---

# 10. Accessing the Nested Values

To get Arjun's name:

```python
print(latest_dictionary["Person1"]["Name"])
```

Output:

```text
Arjun
```

To get Arjun's age:

```python
print(latest_dictionary["Person1"]["Age"])
```

Output:

```text
25
```

To get Nakul's name:

```python
print(latest_dictionary["Person2"]["Name"])
```

Output:

```text
Nakul
```

To get Nakul's age:

```python
print(latest_dictionary["Person2"]["Age"])
```

Output:

```text
26
```

---

# 11. Understanding the Two-Level Access

Consider:

```python
latest_dictionary["Person1"]["Name"]
```

Python performs two lookups.

### First lookup

```python
latest_dictionary["Person1"]
```

returns:

```python
{
    "Name": "Arjun",
    "Age": 25
}
```

### Second lookup

Then:

```python
["Name"]
```

returns:

```text
Arjun
```

So:

```text
latest_dictionary
       ↓
   Person1
       ↓
     Name
       ↓
     Arjun
```

---

# 12. Complete Example

```python
latest_dictionary = {}

latest_dictionary["Person1"] = {
    "Name": "Arjun",
    "Age": 25,
}

latest_dictionary["Person2"] = {
    "Name": "Nakul",
    "Age": 26,
}

print(latest_dictionary)

print(latest_dictionary["Person1"]["Name"])
print(latest_dictionary["Person1"]["Age"])

print(latest_dictionary["Person2"]["Name"])
print(latest_dictionary["Person2"]["Age"])
```

Output:

```text
{
    'Person1': {'Name': 'Arjun', 'Age': 25},
    'Person2': {'Name': 'Nakul', 'Age': 26}
}

Arjun
25
Nakul
26
```

---

# 13. Alternative – List of Dictionaries

For storing multiple people, another common approach is a **list containing dictionaries**.

```python
people = []

people.append({
    "Name": "Arjun",
    "Age": 25
})

people.append({
    "Name": "Nakul",
    "Age": 26
})

print(people)
```

Output:

```text
[
    {'Name': 'Arjun', 'Age': 25},
    {'Name': 'Nakul', 'Age': 26}
]
```

This is often useful when you have a collection of similar records.

---

# 14. Dictionary vs List of Dictionaries

### Nested dictionary

```python
people = {
    "Person1": {
        "Name": "Arjun",
        "Age": 25
    },
    "Person2": {
        "Name": "Nakul",
        "Age": 26
    }
}
```

Good when you have a unique identifier such as:

```text
Person1
Person2
Employee001
Employee002
```

### List of dictionaries

```python
people = [
    {"Name": "Arjun", "Age": 25},
    {"Name": "Nakul", "Age": 26}
]
```

Good when you mainly have a collection of records and don't need a dictionary key for each record.

---

# 15. Key Concept – Add vs Update

Remember this rule:

```python
dictionary["key"] = value
```

### New key

If the key doesn't exist:

```python
dictionary["Name"] = "Ram"
```

**Adds** the key.

### Existing key

If the key already exists:

```python
dictionary["Name"] = "Sri"
```

**Updates/replaces** the value.

---

# 16. Visual Summary

### One person

```text
Dictionary
│
├── Name → Ram
└── Age  → 25
```

Updating:

```text
Name → Ram
  ↓
Name → Sri
```

Only one person is represented.

---

### Multiple people

```text
Dictionary
│
├── Person1
│   ├── Name → Arjun
│   └── Age  → 25
│
└── Person2
    ├── Name → Nakul
    └── Age  → 26
```

Now both people can exist because their **outer keys are different**.

---

# 17. Key Takeaways

```text
1. Dictionaries store key/value pairs.

2. Dictionary keys must be unique.

3. Adding a new key creates a new entry.

4. Assigning a value to an existing key updates it.

5. The same key cannot represent multiple values simultaneously.

6. Use nested dictionaries to group multiple records
   using unique keys.

7. A list of dictionaries is another common way
   to store multiple records.

8. Nested dictionary access uses:
   dictionary["outer_key"]["inner_key"]
```

## Core Pattern

### Updating a value

```python
dictionary["Name"] = "Ram"

dictionary["Name"] = "Sri"
```

Result:

```python
{"Name": "Sri"}
```

### Storing multiple people

```python
people = {}

people["Person1"] = {
    "Name": "Arjun",
    "Age": 25
}

people["Person2"] = {
    "Name": "Nakul",
    "Age": 26
}
```

Result:

```text
Person1 → Arjun, 25
Person2 → Nakul, 26
```
