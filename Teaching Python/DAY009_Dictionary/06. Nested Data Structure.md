# Python Nested Data Structures

## 1. Objective

This exercise demonstrates how Python data structures can be **nested inside each other**.

Examples covered:

* Dictionary containing strings
* Dictionary containing lists
* List containing another list
* Dictionary containing another dictionary
* Dictionary → Dictionary → List
* Accessing nested values using keys and indexes

---

# 2. Dictionary with Simple Values

```python id="q0u5kv"
capitals = {
    "India": "Delhi",
    "UK": "London"
}
```

This is a simple dictionary.

The structure is:

```text id="qk5n6d"
Key       → Value
------------------
India     → Delhi
UK        → London
```

To access a value:

```python id="qk4g1c"
print(capitals["India"])
```

Output:

```text id="n4e3t9"
Delhi
```

---

# 3. Dictionary Containing Lists

A dictionary can contain a **list as its value**.

```python id="tq7qdy"
places_visited = {
    "India": ["Delhi", "Chennai", "Mumbai"],
    "UK": ["London", "Wales", "Scotland"]
}
```

The structure is:

```text id="p1n9jv"
places_visited
│
├── India → ["Delhi", "Chennai", "Mumbai"]
│
└── UK → ["London", "Wales", "Scotland"]
```

---

# 4. Print the Entire Dictionary

```python id="q7r7yb"
print(places_visited)
```

Output:

```text id="sh30eo"
{
    'India': ['Delhi', 'Chennai', 'Mumbai'],
    'UK': ['London', 'Wales', 'Scotland']
}
```

---

# 5. Access the List Inside the Dictionary

```python id="v3k8kq"
print(places_visited["India"])
```

Output:

```text id="a0jj6y"
['Delhi', 'Chennai', 'Mumbai']
```

Here:

```python id="qkpp91"
places_visited["India"]
```

returns the **list** associated with the `"India"` key.

---

# 6. Access an Item Inside the Nested List

To get `"Chennai"`:

```python id="2uq9hz"
print(places_visited["India"][1])
```

Output:

```text id="w6u4ve"
Chennai
```

Why `[1]`?

Because Python lists use **zero-based indexing**:

```text id="y8yds0"
Index       Value
-------------------
[0]         Delhi
[1]         Chennai
[2]         Mumbai
```

So:

```python id="zh5zch"
places_visited["India"][1]
```

means:

```text id="a9p1nd"
Dictionary
    ↓
"India"       → get the value
    ↓
List
    ↓
[1]           → get second item
    ↓
"Chennai"
```

---

# 7. Nested List

A list can also contain another list.

```python id="r9y17u"
nested_list = ["A", "B", ["C", "D"]]
```

The structure is:

```text id="t23h7f"
nested_list
│
├── [0] → A
├── [1] → B
│
└── [2] → ["C", "D"]
             │
             ├── [0] → C
             └── [1] → D
```

---

# 8. Accessing `D` from the Nested List

```python id="9evu9n"
print(nested_list[2][1])
```

Output:

```text id="l7e5a1"
D
```

This works in two steps:

```text id="4k2m2g"
nested_list[2]
       ↓
["C", "D"]
       ↓
     [1]
       ↓
      D
```

So:

```python id="g5c7mc"
nested_list[2][1]
```

means:

> Get item `2` from the outer list, then get item `1` from the inner list.

---

# 9. Dictionary Containing Another Dictionary

A dictionary can also contain another dictionary.

```python id="t8k1jy"
my_travel_blog = {
    "India": {
        "States Visited": 20,
        "Top Cities Seen": ["Delhi", "Chennai", "Mumbai"]
    },
    "UK": {
        "Counties Visited": 10,
        "Top Cities Seen": ["London", "Wales", "Scotland"]
    }
}
```

This is called a **nested dictionary**.

---

# 10. Structure of the Travel Blog

```text id="7ibc8r"
my_travel_blog
│
├── India
│   │
│   ├── States Visited → 20
│   │
│   └── Top Cities Seen
│       │
│       └── ["Delhi", "Chennai", "Mumbai"]
│
└── UK
    │
    ├── Counties Visited → 10
    │
    └── Top Cities Seen
        │
        └── ["London", "Wales", "Scotland"]
```

Notice that we now have:

```text id="2r5a2n"
Dictionary
    ↓
Dictionary
    ↓
List
```

---

# 11. Print the Entire Nested Dictionary

```python id="f1wx7x"
print(my_travel_blog)
```

Output:

```text id="6t3kpn"
{
    'India': {
        'States Visited': 20,
        'Top Cities Seen': ['Delhi', 'Chennai', 'Mumbai']
    },
    'UK': {
        'Counties Visited': 10,
        'Top Cities Seen': ['London', 'Wales', 'Scotland']
    }
}
```

---

# 12. Access Chennai

To print `"Chennai"`:

```python id="8y0shp"
print(my_travel_blog["India"]["Top Cities Seen"][1])
```

Output:

```text id="b8w7jc"
Chennai
```

There are **three levels of access** here:

```text id="2h0q4m"
my_travel_blog
       ↓
    "India"
       ↓
"Top Cities Seen"
       ↓
      [1]
       ↓
   "Chennai"
```

---

# 13. Understanding the Three Levels

The following:

```python id="wq6xg2"
my_travel_blog["India"]["Top Cities Seen"][1]
```

can be broken down into:

### Level 1 – Dictionary

```python id="6zv0oe"
my_travel_blog["India"]
```

Returns:

```python id="lh3cjj"
{
    "States Visited": 20,
    "Top Cities Seen": ["Delhi", "Chennai", "Mumbai"]
}
```

### Level 2 – Nested Dictionary

```python id="b7d1qk"
my_travel_blog["India"]["Top Cities Seen"]
```

Returns:

```python id="6y3p9h"
["Delhi", "Chennai", "Mumbai"]
```

### Level 3 – List

```python id="f1j3mp"
my_travel_blog["India"]["Top Cities Seen"][1]
```

Returns:

```text id="x6b8bz"
Chennai
```

---

# 14. Important Rule – Dictionary vs List

This is one of the most important concepts.

## Dictionary

Use a **key**:

```python id="g9f3yq"
dictionary["key"]
```

Example:

```python id="f6f7x5"
my_travel_blog["India"]
```

---

## List

Use an **index**:

```python id="5q5y4f"
my_list[0]
my_list[1]
my_list[2]
```

Example:

```python id="l5pqye"
["Delhi", "Chennai", "Mumbai"][1]
```

returns:

```text id="48axm4"
Chennai
```

---

# 15. Combining Keys and Indexes

Nested structures can combine both.

For example:

```python id="8rjv19"
my_travel_blog["India"]["Top Cities Seen"][1]
```

contains:

```text id="j26ohq"
["India"]          → Dictionary key
["Top Cities Seen"] → Dictionary key
[1]                → List index
```

Therefore:

```text id="zj2jpx"
Dictionary → Dictionary → List → Item
```

---

# 16. Another Example

Consider:

```python id="jv7f9q"
company = {
    "Employee": {
        "Name": "Sriram",
        "Skills": ["Linux", "Python", "Kubernetes"]
    }
}
```

To get the name:

```python id="p3t9ae"
print(company["Employee"]["Name"])
```

Output:

```text id="1ytv5x"
Sriram
```

To get `"Python"`:

```python id="7sm7c6"
print(company["Employee"]["Skills"][1])
```

Output:

```text id="zmx9rj"
Python
```

Again:

```text id="4p9kwq"
Dictionary → Dictionary → List → Index
```

# 17. Quick Comparison

| Structure                      | Example                                       | Access                       |
| ------------------------------ | --------------------------------------------- | ---------------------------- |
| Dictionary                     | `{"India": "Delhi"}`                          | `data["India"]`              |
| List                           | `["Delhi", "Chennai"]`                        | `data[0]`                    |
| Dictionary → List              | `{"India": ["Delhi", "Chennai"]}`             | `data["India"][1]`           |
| List → List                    | `["A", ["B", "C"]]`                           | `data[1][0]`                 |
| Dictionary → Dictionary        | `{"India": {"Capital": "Delhi"}}`             | `data["India"]["Capital"]`   |
| Dictionary → Dictionary → List | `{"India": {"Cities": ["Delhi", "Chennai"]}}` | `data["India"]["Cities"][1]` |

---

# 18. Key Takeaways

```text id="mnyk5q"
1. Dictionaries use KEYS.

2. Lists use INDEXES.

3. A dictionary can contain a list.

4. A list can contain another list.

5. A dictionary can contain another dictionary.

6. Different data structures can be nested together.

7. Always look at the structure before deciding
   whether to use a key or an index.
```

## The Most Important Pattern

```python id="3f3hja"
data["key"]["key"][index]
```

For your example:

```python id="k7t7j3"
my_travel_blog["India"]["Top Cities Seen"][1]
```

means:

```text id="2i2k6g"
my_travel_blog
      ↓
   "India"             ← dictionary key
      ↓
"Top Cities Seen"      ← dictionary key
      ↓
     [1]               ← list index
      ↓
   "Chennai"
```

### Remember

**`[]` does not always mean an index.**

It depends on the data structure:

```text id="b9i1h4"
Dictionary → ["key"]
List       → [index]
```

That distinction is fundamental when working with nested Python data.
