# Python Blind Auction – Highest Bid

## Objective

Write a Python program that:

1. Accepts a bidder's name.
2. Accepts the bidder's bid amount.
3. Stores the bidder and amount in a dictionary.
4. Allows multiple people to place bids.
5. Hides the previous bid before the next bidder enters.
6. Finds the highest bid.
7. Displays the winner and their bid amount.

---

## Complete Program

```python
# Write a Python program to generate a bid
# with name and amount and find who is highest.

bids = {}

# 1. Get user input first
name = input("Enter the name ")
price = int(input("Enter the bid amount "))

# 2. Save data to dictionary
bids[name] = price

# 3. Do you want to continue?
proceed = input("Do you want to Continue Y/N ").lower()

while proceed == "y":

    # Hide the previous bidder's information
    print("\n" * 20)

    name = input("Enter the name ")
    price = int(input("Enter the bid amount "))

    # Save bid
    bids[name] = price

    # Ask whether another bidder wants to continue
    proceed = input("Do you want to Continue Y/N: ").lower()

# Hide the bidding information
print("\n" * 20)


# 4. Compare the bids in the dictionary
def find_highest_bid(bidding_dictionary):

    highest_bid = 0
    winner = ""

    for bidder in bidding_dictionary:

        bid_amount = bidding_dictionary[bidder]

        if bid_amount > highest_bid:

            highest_bid = bid_amount
            winner = bidder

    print(
        f"The Winner is {winner} with a highest bid of {highest_bid}"
    )


# 5. Find the winner
find_highest_bid(bids)
```

# 4. Ask Whether to Continue

```python
proceed = input("Do you want to Continue Y/N ").lower()
```

`.lower()` converts the input to lowercase.

Therefore:

```text
Y → y
y → y
N → n
n → n
```

So the loop should check:

```python
while proceed == "y":
```

and not:

```python
while proceed == "Y":
```

The loop continues while the user enters `y`.

# 6. Why `print("\n" * 20)`?

```python
print("\n" * 20)
```

prints 20 newline characters.

This creates blank space in the terminal and hides the previous bidder's information from the next bidder.

This is useful for a blind auction.

### Important

This does **not actually clear the terminal**.

It simply prints many blank lines.

For this beginner exercise, that is perfectly acceptable.

# 13. Complete Highest-Bid Function

```python
def find_highest_bid(bidding_dictionary):

    highest_bid = 0
```

# 16. How the Highest-Bid Logic Works

Suppose:

```python
bids = {
    "Sriram": 100,
    "Ravi": 150,
    "John": 120
}
```

Initially:

```python
highest_bid = 0
winner = ""
```

### First iteration

```text
bidder = Sriram
bid_amount = 100
```

Check:

```python

```

True.

Update:

```python
highest_bid = 100
winner = "Sriram"
```

---

### Second iteration

```text
bidder = Ravi
bid_amount = 150
```

Check:

```python
150 > 100
```

True.

Update:

```python
highest_bid = 150
winner = "Ravi"
```

---

### Third iteration

```text
bidder = John
bid_amount = 120
```

Check:

```python
120 > 150
```

False.

Nothing changes.

Final values:

```python
highest_bid = 150
winner = "Ravi"
```

Result:

```text
The Winner is Ravi with a highest bid of 150
```

# 18. Key Things to Remember

## Dictionary Structure

Remember:

```python
bids[name] = price
```

Think:

```text
NAME → BID
```

Example:

```text
Sriram → 100
Ravi   → 150
John   → 120
```

---

## `.lower()` and `while`

If you write:

```python
proceed = input(...).lower()
```

then compare with:

```python
while proceed == "y":
```

not:

```python
while proceed == "Y":
```

---

## Update the Loop Condition

Always ask for the next value inside the loop:

```python
while proceed == "y":

    # do something

    proceed = input(...).lower()
```

If you don't update `proceed`, the loop can become an infinite loop.

---

## Dictionary Iteration

This:

```python
for bidder in bidding_dictionary:
```

gives the dictionary keys.

Then:

```python
bidding_dictionary[bidder]
```

gets the corresponding value.

# 20. Common Mistakes

### Mistake 1 — Wrong dictionary assignment

Incorrect:

```python
bids[name] = name
bids[price] = price
```

Correct:

```python
bids[name] = price
```

---

### Mistake 2 — Wrong case

Incorrect:

```python
proceed = input(...).lower()

while proceed == "Y":
```

Correct:

```python
proceed = input(...).lower()

while proceed == "y":
```

---

### Mistake 3 — Infinite loop

Incorrect:

```python
while proceed == "y":

    name = input(...)
    price = int(input(...))
```

There is no new value for `proceed`.

Correct:

```python
while proceed == "y":

    name = input(...)
    price = int(input(...))

    proceed = input("Continue Y/N: ").lower()
```

---

### Mistake 4 — Incorrect `for` syntax

Incorrect:

```python
for bidder in bidding_dictionary::
```

Correct:

```python
for bidder in bidding_dictionary:
```

---

### Mistake 5 — Forgetting to call the function

Defining:

```python
def find_highest_bid(bidding_dictionary):
```

does not run the function.

You need:

```python
find_highest_bid(bids)
```

## Core Pattern

```python
bids[name] = price

for bidder in bids:
    bid_amount = bids[bidder]

    if bid_amount > highest_bid:
        highest_bid = bid_amount
        winner = bidder
```

This pattern is useful beyond auctions: it is a common way to **find the maximum value in a dictionary and identify the key associated with it**.
