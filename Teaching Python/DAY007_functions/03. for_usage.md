# Python `for` Loop with `if` Statement Example

## Problem Statement

Write a `for` loop to iterate through a list of numbers.

If a number is **even**, print its **square** (`num ** 2`).

---

# Program

```python
numbers = [1, 4, 7, 10, 13, 16, 19, 22]

for num in numbers:
    if num % 2 == 0:
        print(f"Square of {num} is {num ** 2}")
```

> **Note:** The original code printed `"Sum of..."`, but since the program calculates the square using `num ** 2`, the message should be **"Square of..."**.

---

# Output

```
Square of 4 is 16
Square of 10 is 100
Square of 16 is 256
Square of 22 is 484
```

---

# Step-by-Step Explanation

## Step 1: Create a List

```python
numbers = [1, 4, 7, 10, 13, 16, 19, 22]
```

A list named `numbers` is created containing eight integers.

---

## Step 2: Start the `for` Loop

```python
for num in numbers:
```

The loop visits each element in the list one by one.

Iteration order:

```
1
4
7
10
13
16
19
22
```

During each iteration, the current value is stored in the variable `num`.

---

## Step 3: Check if the Number is Even

```python
if num % 2 == 0:
```

The `%` operator is called the **modulus operator**.

It returns the remainder after division.

Examples

```
4 % 2 = 0   ✅ Even
7 % 2 = 1   ❌ Odd
10 % 2 = 0  ✅ Even
13 % 2 = 1  ❌ Odd
```

If the remainder is `0`, the number is even.

---

## Step 4: Calculate the Square

```python
num ** 2
```

The `**` operator means **power (exponentiation)**.

Examples

```
4 ** 2 = 16
10 ** 2 = 100
16 ** 2 = 256
22 ** 2 = 484
```

---

## Step 5: Print the Result

```python
print(f"Square of {num} is {num ** 2}")
```

This uses an **f-string** to insert the values directly into the output.

Example

```
Square of 10 is 100
```

# Important Concepts

## `for` Loop

Repeats a block of code for every item in a sequence.

```python
for item in sequence:
    # code
```

---

## `%` (Modulus Operator)

Returns the remainder after division.

Examples

```python
8 % 2
```

Output

```
0
```

```python
9 % 2
```

Output

```
1
```

---

## `**` (Exponent Operator)

Raises a number to a power.

Examples

```python
5 ** 2
```

Output

```
25
```

```python
2 ** 5
```

Output

```
32
```

# Interview / Exam Questions

### Q1. What does a `for` loop do?

It repeats a block of code for each item in a sequence (such as a list).

---

### Q2. How do you check whether a number is even?

```python
num % 2 == 0
```

---

### Q3. What does `**` mean in Python?

It is the exponent (power) operator.

Example

```python
6 ** 2
```

Output

```
36
```

---

### Q4. What is an f-string?

An f-string allows variables and expressions to be embedded directly inside a string.

Example

```python
name = "Alice"

print(f"Hello {name}")
```

Output

```
Hello Alice
```

# Summary

| Statement | Purpose |
|-----------|---------|
| `for num in numbers:` | Iterate through each number in the list |
| `num % 2 == 0` | Check if the number is even |
| `num ** 2` | Calculate the square of the number |
| `print()` | Display the result |
| `f"..."` | Format the output using an f-string |
