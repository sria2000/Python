# Python User-Defined Function Example

## Program

```python
def my_print():
    a = int(input("Enter first no: "))
    b = int(input("Enter second no: "))
    total = a + b
    print(total)

my_print()
```

---

# Output (Example)

```
Enter first no: 10
Enter second no: 20
30
```

---

# Step-by-Step Explanation

## Step 1: Define the Function

```python
def my_print():
```

- `def` is the keyword used to create a function.
- `my_print` is the function name.
- The parentheses `()` indicate that this function takes **no parameters**.
- The colon `:` marks the beginning of the function body.

> At this stage, Python **only stores the function**. It does **not** execute it.

---

## Step 2: Read the First Number

```python
a = int(input("Enter first no: "))
```

What happens?

1. `input()` displays the message:
   ```
   Enter first no:
   ```
2. The user types a value.
3. `input()` always returns a **string**.
4. `int()` converts the string into an integer.
5. The value is stored in variable `a`.

Example

```
User enters: 10
```

Now,

```python
a = 10
```

---

## Step 3: Read the Second Number

```python
b = int(input("Enter second no: "))
```

Exactly the same process happens.

Example

```
User enters: 20
```

Now,

```python
b = 20
```

---

## Step 4: Add the Numbers

```python
total = a + b
```

Python adds the two values.

Example

```python
total = 10 + 20
```

Result

```python
total = 30
```

> **Note:** Although the original code used the variable name `sum`, it is better to use `total` because `sum` is a built-in Python function.

---

## Step 5: Display the Result

```python
print(total)
```

Displays

```
30
```

on the screen.

---

## Step 6: Call the Function

```python
my_print()
```

This executes the function.

Without this line, nothing inside the function will run.

---

# Dry Run

Suppose the user enters:

```
First Number  = 25
Second Number = 15
```

Execution

| Line | Action | Value |
|------|--------|-------|
| `a = int(input())` | Read first number | `a = 25` |
| `b = int(input())` | Read second number | `b = 15` |
| `total = a + b` | Add numbers | `40` |
| `print(total)` | Display answer | `40` |

Output

```
40
```

---

# Important Points

- `def` creates a function.
- `input()` accepts user input.
- `input()` returns a **string**.
- `int()` converts the string to an integer.
- `print()` displays the output.
- A function only runs when it is called.
- Variables `a`, `b`, and `total` are **local variables** because they exist only inside the function.

---

# Interview / Exam Questions

### Q1. What does `def` do?

It defines (creates) a function.

---

### Q2. Does a function execute when it is defined?

No. It executes only when it is called.

---

### Q3. Why do we use `int(input())`?

Because `input()` returns a string, and `int()` converts it into an integer so arithmetic operations can be performed.

---

### Q4. Can we call the function multiple times?

Yes.

Example

```python
my_print()
my_print()
my_print()
```

The program will ask for two numbers three times.

---

# Summary

- `def` → Creates a function.
- `input()` → Reads user input.
- `int()` → Converts input to an integer.
- `+` → Adds the numbers.
- `print()` → Displays the result.
- `my_print()` → Calls and executes the function.
