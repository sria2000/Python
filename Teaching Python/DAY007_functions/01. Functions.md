# Python Functions

## What are Functions?

A **function** is a block of reusable code that performs a specific task.

### Benefits
- Reduces code duplication (DRY - Don't Repeat Yourself)
- Makes code easier to read
- Easier to maintain and debug
- Improves code reusability

---

# Types of Functions

There are two types of functions in Python:

1. **Built-in Functions**
2. **User-defined Functions**

---

# 1. Built-in Functions

Python provides many ready-made functions.

## len()

Returns the number of items in an object.

```python
name = "Python"

print(len(name))
```

**Output**

```
6
```

Example with a list

```python
numbers = [10, 20, 30, 40]

print(len(numbers))
```

Output

```
4
```

---

## int()

Converts a value into an integer.

```python
age = int("25")

print(age)
```

Output

```
25
```

Example

```python
num = int(12.8)

print(num)
```

Output

```
12
```

---

## range()

Generates a sequence of numbers.

### Syntax

```python
range(start, stop, step)
```

Examples

```python
for i in range(5):
    print(i)
```

Output

```
0
1
2
3
4
```

Example

```python
for i in range(1, 6):
    print(i)
```

Output

```
1
2
3
4
5
```

Example with step

```python
for i in range(0, 10, 2):
    print(i)
```

Output

```
0
2
4
6
8
```

---

## eval()

Evaluates a string as a Python expression.

### Syntax

```python
eval(expression)
```

Example

```python
result = eval("10 + 20")

print(result)
```

Output

```
30
```

Example

```python
a = 10
b = 5

print(eval("a * b"))
```

Output

```
50
```

> **Note:** Avoid using `eval()` with user input because it can execute malicious code.

---

## exec()

Executes dynamically created Python code.

### Syntax

```python
exec(code)
```

Example

```python
code = """
for i in range(3):
    print(i)
"""

exec(code)
```

Output

```
0
1
2
```

Example

```python
exec("x = 100")
print(x)
```

Output

```
100
```

> **Note:** `exec()` is powerful but should not be used on untrusted input.

---

# 2. User-defined Functions

User-defined functions are functions created by the programmer.

### Syntax

```python
def function_name():
    # function body
```

Example

```python
def greet():
    print("Welcome to Python")

greet()
```

Output

```
Welcome to Python
```

---

# Example: Adding Two Numbers

```python
def my_print():
    a = int(input("Enter first no: "))
    b = int(input("Enter second no: "))

    total = a + b

    print(total)

my_print()
```

### Sample Output

```
Enter first no: 10
Enter second no: 20
30
```

### Explanation

```python
def my_print():
```

Creates a function named `my_print`.

```python
a = int(input("Enter first no: "))
```

Reads the first number from the user and converts it to an integer.

```python
b = int(input("Enter second no: "))
```

Reads the second number.

```python
total = a + b
```

Adds both numbers.

```python
print(total)
```

Displays the result.

```python
my_print()
```

Calls (executes) the function.

# Important Notes

- A function **does not execute when it is defined**.
- It only executes when it is **called**.
- A function can be called multiple times.
- Variables created inside a function are called **local variables**.

Example

```python
def hello():
    print("Hello")

hello()
hello()
hello()
```

Output

```
Hello
Hello
Hello
```

# Summary

| Function | Purpose | Example |
|----------|---------|---------|
| `len()` | Returns length | `len("Python")` |
| `int()` | Converts to integer | `int("10")` |
| `range()` | Generates sequence | `range(5)` |
| `eval()` | Evaluates an expression | `eval("5+5")` |
| `exec()` | Executes Python code | `exec("print('Hi')")` |
| User-defined | Created by programmer | `def my_print():` |

✅ `int()` → Converts to integer

✅ `eval()` → Evaluates an expression (use with caution)

✅ `exec()` → Executes Python code (avoid untrusted input)
