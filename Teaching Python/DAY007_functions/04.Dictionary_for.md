# Python Dictionary `.items()` with `for` Loop Example

## Problem Statement

Write a `for` loop using `.items()` to print resources where the status is `"production"`.

---

# Program

```python
resources = {
    "server-01": "production",
    "server-02": "staging",
    "db-main": "production",
    "test-runner": "development",
}

for name, env in resources.items():
    if env == "production":
        print(f"The name of the server is {name}")
```

---

# Output

```
The name of the server is server-01
The name of the server is db-main
```

---

# Step-by-Step Explanation

## Step 1: Create a Dictionary

```python
resources = {
    "server-01": "production",
    "server-02": "staging",
    "db-main": "production",
    "test-runner": "development",
}
```

A dictionary stores data as **key-value pairs**.

Structure:

```
key : value
```

Example:

```
server-01 : production
```

Here:

| Resource Name (Key) | Environment (Value) |
|---|---|
| server-01 | production |
| server-02 | staging |
| db-main | production |
| test-runner | development |

---

# Step 2: Use `.items()`

```python
for name, env in resources.items():
```

The `.items()` method returns both:

- **Key**
- **Value**

from the dictionary.

Example:

```python
resources.items()
```

Returns:

```
("server-01", "production")
("server-02", "staging")
("db-main", "production")
("test-runner", "development")
```

During each loop:

| Iteration | name | env |
|---|---|---|
| 1 | server-01 | production |
| 2 | server-02 | staging |
| 3 | db-main | production |
| 4 | test-runner | development |

---

# Step 3: Check Environment

```python
if env == "production":
```

The program checks whether the resource environment is production.

Only matching resources will be printed.

Examples:

```
server-01 → production ✅
server-02 → staging ❌
db-main → production ✅
test-runner → development ❌
```

---

# Step 4: Print Resource Name

```python
print(f"The name of the server is {name}")
```

An f-string is used to insert the variable value into the message.

Example:

```python
name = "server-01"
```

Output:

```
The name of the server is server-01
```

# Dictionary Loop Methods

## 1. Loop Through Keys

```python
for name in resources:
    print(name)
```

Output:

```
server-01
server-02
db-main
test-runner
```

---

## 2. Loop Through Values

```python
for env in resources.values():
    print(env)
```

Output:

```
production
staging
production
development
```

---

## 3. Loop Through Keys and Values

```python
for name, env in resources.items():
    print(name, env)
```

Output:

```
server-01 production
server-02 staging
db-main production
test-runner development
```

# Important Concepts

## Dictionary

Stores data in key-value pairs.

Example:

```python
server = {
    "name": "web01",
    "status": "running"
}
```

---

## `.items()`

Returns both key and value.

Syntax:

```python
dictionary.items()
```

Example:

```python
for key, value in dictionary.items():
    print(key, value)
```

---

## `if` Condition

Used for decision making.

Example:

```python
if env == "production":
    print(name)
```

Only runs when the condition is true.

---

# Real-World DevOps Example

A similar pattern can be used to:

- Find production servers
- Filter Kubernetes resources
- Check AWS instances by environment
- Identify production deployments

Example:

```python
servers = {
    "web01": "production",
    "web02": "testing",
    "db01": "production"
}

for server, environment in servers.items():
    if environment == "production":
        print(f"Deploying to {server}")
```

Output:

```
Deploying to web01
Deploying to db01
```

---

# Summary

| Concept | Purpose |
|---|---|
| Dictionary | Stores key-value data |
| `.items()` | Returns key and value together |
| `for` loop | Iterates through items |
| `if` condition | Filters matching values |
| f-string | Formats output |

**Key exam pattern:**

```python
for key, value in dictionary.items():
    if value == "something":
        print(key)
```

This pattern is commonly used in Python automation and DevOps scripting.
