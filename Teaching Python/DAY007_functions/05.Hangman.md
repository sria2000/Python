# Python Project: Hangman Game

## Objective

Design a simple **Hangman** game where:

- A random word is selected from a list.
- The player guesses one letter at a time.
- If the letter exists in the word, it is revealed.
- If the letter is incorrect, one life is lost.
- The game continues until:
  - The player guesses the entire word, or
  - The player runs out of lives.

---

# Program

```python
import random

word_list = ["tiger", "lion", "rabbit", "cow"]

# Randomly choose a word
select_word = random.choice(word_list)

# Length of the chosen word
length_hint = len(select_word)

progress = 0
lives = 10

# Display hidden letters using underscores
display = ["_"] * length_hint

print(f"This word has length of {length_hint}")
print(f"You have {lives} lives left")
print(" ".join(display))

while progress < length_hint and lives > 0:

    choose = input("Enter a character: ").lower()

    if choose in select_word:

        for i in range(length_hint):

            if select_word[i] == choose and display[i] == "_":
                display[i] = choose
                progress += 1

        print("Good Guess!")
        print(" ".join(display))

    else:
        lives -= 1
        print(f"Wrong choice. Lives left: {lives}")
        print(" ".join(display))

if lives > 0:
    print(f"Congratulations! You guessed the word: {''.join(display)}")
else:
    print(f"Sorry! You lost. The correct word was: {select_word}")
```

---

---

## `range()`

Generates a sequence of numbers.

```python

```
