# Python Lists

## What is a List?

A **list** in Python is a collection used to store multiple values in a single variable.

Example:

```python
fruits = ["banana", "apple"]
```

A list can store:

- Names
- Numbers
- Strings
- Objects
- Other lists (nested lists)

---

# Creating a List

Lists are created using:

```
[ ]
```

Square brackets are used to start and end a list.

Example:

```python
fruits = [
    "banana",
    "apple"
]
```

Structure:

```
List
 |
 |-- banana
 |
 |-- apple
```

---

# Example: Store All States in USA

```python
states = [
    "Alabama",
    "Alaska",
    "Arizona",
    "Arkansas",
    "California",
    "Colorado",
    "Florida",
    "Texas"
]
```

A list helps store related data together.

---

# List Maintains Order

Python lists are **ordered**.

Example:

```python
fruits = [
    "banana",
    "apple",
    "orange"
]
```

The order is maintained:

```
Index 0 -> banana
Index 1 -> apple
Index 2 -> orange
```

---

# List Indexing

Every item in a list has an index.

Important:

- Index starts from **0**
- First item = index 0
- Second item = index 1

Example:

```python
fruits = [
    "banana",
    "apple",
    "orange"
]

print(fruits[0])
```

Output:

```
banana
```

---

## Access Second Item

```python
print(fruits[1])
```

Output:

```
apple
```

---

# Negative Indexing

Python also supports negative indexes.

Example:

```python
fruits = [
    "banana",
    "apple",
    "orange"
]

print(fruits[-1])
```

Output:

```
orange
```

Meaning:

| Index | Value |
|---|---|
| -1 | Last item |
| -2 | Second last item |
| -3 | Third last item |

---

# Adding Items Inside a List

## append()

`append()` adds an item at the end of the list.

Example:

```python
fruits = [
    "banana",
    "apple"
]

fruits.append("orange")

print(fruits)
```

Output:

```
[
"banana",
"apple",
"orange"
]
```

---

# Adding Multiple Items

## extend()

`extend()` adds multiple items.

Example:

```python
fruits = [
    "banana",
    "apple"
]

fruits.extend(
    [
        "orange",
        "mango"
    ]
)

print(fruits)
```

Output:

```
[
"banana",
"apple",
"orange",
"mango"
]
```

---

# Updating List Items

Lists are **mutable**.

This means values can be changed.

Example:

```python
fruits = [
    "banana",
    "apple"
]

fruits[0] = "grapes"

print(fruits)
```

Output:

```
[
"grapes",
"apple"
]
```

---

# Removing Items

## remove()

Removes a specific value.

Example:

```python
fruits.remove("apple")

print(fruits)
```

---

## pop()

Removes an item using index.

Example:

```python
fruits.pop(0)
```

Removes the first item.

---

# Finding Number of Items

Use:

```python
len()
```

Example:

```python
fruits = [
    "banana",
    "apple",
    "orange"
]

print(len(fruits))
```

Output:

```
3
```

---

# Loop Through a List

Example:

```python
fruits = [
    "banana",
    "apple",
    "orange"
]

for fruit in fruits:
    print(fruit)
```

Output:

```
banana
apple
orange
```

---

# Checking if Item Exists

Use `in`.

Example:

```python
fruits = [
    "banana",
    "apple",
    "orange"
]

if "apple" in fruits:
    print("Apple exists")
```

Output:

```
Apple exists
```

---

# Nested Lists

A list can contain another list.

Example:

```python
fruits = [
    "banana",
    "apple"
]

vegetables = [
    "spinach",
    "potato"
]


food = [
    fruits,
    vegetables
]
```

Structure:

```
food

|
|-- fruits
|     |
|     |-- banana
|     |-- apple
|
|-- vegetables
      |
      |-- spinach
      |-- potato
```

Access:

```python
print(food[1][0])
```

Output:

```
spinach
```

Explanation:

```
food[1]  -> vegetables

food[1][0] -> spinach
```

# List vs Other Data Types

| Feature | List |
|---|---|
| Ordered | Yes |
| Changeable | Yes |
| Allows duplicates | Yes |
| Uses | `[ ]` |
| Index based | Yes |

Example:

```python
numbers = [1,2,3,3]
```

Duplicate values are allowed.

# Common List Functions

| Function | Purpose | Example |
|---|---|---|
| len() | Count items | `len(list)` |
| append() | Add one item | `list.append()` |
| extend() | Add multiple items | `list.extend()` |
| remove() | Remove value | `list.remove()` |
| pop() | Remove by index | `list.pop()` |
| sort() | Sort list | `list.sort()` |
| reverse() | Reverse order | `list.reverse()` |

# Interview Questions

## Q1: What is a Python list?

A collection that stores multiple ordered and changeable values.

Example:

```python
names = ["Sri","Ram"]
```

## Q2: Are Python lists mutable?

Yes.

Example:

```python
names[0] = "John"
```

---

## Q3: What index does Python start with?

Python starts indexing from:

```
0
```

---

## Q4: Difference between append() and extend()?

### append()

Adds one item:

```python
list.append("item")
```

### extend()

Adds multiple items:

```python
list.extend(["a","b"])
```

