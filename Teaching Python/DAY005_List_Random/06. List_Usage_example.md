# Python Lists - List of States in America

## What is a List?

A **list** in Python is an ordered, changeable (mutable) collection that allows duplicate values.

Example:

```python
my_list = ["Apple", "Banana", "Orange"]
```

Lists use **square brackets `[]`** and items are separated by commas.

---

```python
list_of_states = [

    "California", "Colorado", "Connecticut",
    "Delaware", "Florida", "Georgia", "Hawaii",
    "Idaho", "Illinois", "Indiana", "Iowa",
```

# Accessing List Elements

Python lists use **index numbers**.

Important:

- Index starts from **0**
- First item = index `0`
- Last item = index `-1`

Example:

```python
# Print first state

print("First state")
print(list_of_states[0])
```

Output:

```
Alabama
```

---

# Find Number of Items in a List

Use the `len()` function.

```python
print(f"There are {len(list_of_states)} states in America")
```

Output:

```
There are 50 states in America
```

---

# Access Last Item in List

Negative indexing starts from the end.

```python
print("Last state is")
print(list_of_states[-1])
```

Output:

```
Wyoming
```

Examples:

| Index | Value |
|---|---|
| 0 | First item |
| 1 | Second item |
| -1 | Last item |
| -2 | Second last item |

---

# Updating List Values

Lists are **mutable**, meaning values can be changed.

Example:

```python
# Swap first two states

list_of_states[0] = "Alaska"
list_of_states[1] = "Alabama"

print(list_of_states)
```

Before:

```
0 - Alabama
1 - Alaska
```

After:

```
0 - Alaska
1 - Alabama
```

---

# Loop Through a List

Using `range()` and `len()`:

```python
for state in range(len(list_of_states)):
    print(state, list_of_states[state])
```

Output:

```
0 Alaska
1 Alabama
2 Arizona
3 Arkansas
...
49 Wyoming
```

Explanation:

```
range(len(list_of_states))
```

will generate:

```
0,1,2,3.....49
```

which represents list indexes.

# Adding Items to a List

## append()

`append()` adds a new item at the end of the list.

Example:

```python
list_of_states.append("Disneyland")

print(list_of_states[-1])
```

Output:

```
Disneyland
```

Before:

```
50 states
```

After:

```
51 items
```

---

# Adding Multiple Items

## extend()

`extend()` adds multiple items from another list.

Example:

```python
list_of_states.extend(
    [
        "Potterland",
        "Crystalmaze Island"
    ]
)

print(list_of_states)
```

Output:

```
[
'Alaska',
'Alabama',
...
'Disneyland',
'Potterland',
'Crystalmaze Island'
]
```

---

# append() vs extend()

| Method | Usage | Example |
|---|---|---|
| append() | Adds one item | `list.append("Texas")` |
| extend() | Adds multiple items | `list.extend(["Texas","Ohio"])` |

Example:

```python
numbers = [1,2,3]

numbers.append([4,5])

print(numbers)
```

Output:

```
[1,2,3,[4,5]]
```

---

Using extend:

```python
numbers = [1,2,3]

numbers.extend([4,5])

print(numbers)
```

Output:

```
[1,2,3,4,5]
```

### Q: Difference between list and tuple?

| List | Tuple |
|---|---|
| Mutable | Immutable |
| Uses `[]` | Uses `()` |
| Can update values | Cannot update values |

Example:

```python
my_list = ["A","B"]
my_tuple = ("A","B")
```
