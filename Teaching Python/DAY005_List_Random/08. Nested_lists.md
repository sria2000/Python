# Python Nested Lists

## What is a Nested List?

A **nested list** is a list that contains one or more lists as its elements.

In Python, lists can store any data type, including another list.

Example:

```python
nested_list = [
    [1,2,3],
    [4,5,6]
]
```

Here:

- The outer list contains two inner lists.
- Each inner list can be accessed using indexes.

---

# Example: Fruits and Vegetables Using Nested Lists

```python
print("Usage of Nested Lists")

Fruits = [
    "Strawberries",
    "Nectarines",
    "Apples",
    "Grapes",
    "Peaches",
    "Cherries",

    "Kale",
    "Celery",
    "Potatoes"

print("Fruit lists")
print(Fruits)

print("Vegetable list")

print("Total list")

print(Total_list)
```

# Understanding the Nested Structure

The `Total_list` contains two lists:

```python
Total_list = [Fruits, Vegetables]
```

Structure:

```
Total_list
│
├── Fruits
│   ├── Strawberries
│   ├── Nectarines
│   ├── Apples
│   ├── Grapes
│   ├── Peaches
│   ├── Cherries
│   ├── Pears
│   └── Tomatoes
│
└── Vegetables
    ├── Spinach
    ├── Kale
    ├── Celery
    └── Potatoes
```

---

# Accessing Items in a Nested List

Nested lists use multiple indexes.

Example:

```python
print(Total_list[0])
```

Output:

```
[
'Strawberries',
'Nectarines',
'Apples',
...
]
```

Explanation:

```
Total_list[0]
```

returns the first inner list (`Fruits`).

---

## Access an Item Inside the Inner List

Example:

```python
print(Total_list[0][2])
```

Output:

```
Apples
```

Explanation:

```
Total_list[0] 
```

gets:

```
Fruits list
```

Then:

```
[2]
```

gets:

```
Apples
```

---

# Access Vegetables

Example:

```python
print(Total_list[1])
```

Output:

```
[
'Spinach',
'Kale',
'Celery',
'Potatoes'
]
```

---

## Access Individual Vegetable

Example:

```python
print(Total_list[1][3])
```

Output:

```
Potatoes
```

Explanation:

```
Total_list[1]
```

selects:

```
Vegetables list
```

Then:

```
[3]
```

selects:

```
Potatoes
```

---

# Loop Through a Nested List

Example:

```python
for category in Total_list:
    for item in category:
        print(item)
```

Output:

```
Strawberries
Nectarines
Apples
Grapes
Peaches
Cherries
Pears
Tomatoes
Spinach
Kale
Celery
Potatoes
```

# Adding Items to a Nested List

Example:

```python
Fruits.append("Banana")

print(Total_list)
```

Output:

```
[
[
'Strawberries',
'Nectarines',
...
'Banana'
],
[
'Spinach',
'Kale',
'Celery',
'Potatoes'
]
]
```

Because `Total_list` contains the reference to `Fruits`, changes are reflected automatically.

# Interview Notes

## Q1: What is a nested list?

A list inside another list.

Example:

```python
list1 = [
    [1,2,3],
    [4,5,6]
]
```

---

## Q2: How do you access values in nested lists?

Using multiple indexes:

```python
list_name[row][column]
```

Example:

```python
matrix[1][2]
```

---

## Q3: Are nested lists mutable?

Yes.

Both the outer list and inner lists can be modified.

Example:

```python
Fruits[0] = "Blueberries"
```

# Key Points

| Concept | Example |
|---|---|
| Normal list | `["Apple","Banana"]` |
| Nested list | `[["Apple"],["Carrot"]]` |
| Access first list | `Total_list[0]` |
| Access item | `Total_list[0][2]` |
| Loop nested list | Nested `for` loops |
| Lists are mutable | Values can be changed |
