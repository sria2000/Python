# Print a Random Number Between `a` and `b`

## Program

```python
import random

a = int(input("Enter a start number: "))
b = int(input("Enter an end number: "))

rand = random.randint(a, b)

print(f"Random number between {a} and {b} is {rand}")
```

---

## Sample Output

```
Enter a start number: 10
Enter an end number: 50
Random number between 10 and 50 is 27
```

---

## Explanation

- `import random` → Imports Python's built-in **random** module.
- `input()` → Reads user input as a string.
- `int()` → Converts the input to an integer.
- `random.randint(a, b)` → Generates a **random integer** between `a` and `b` **(both inclusive)**.
- `print()` → Displays the generated random number.

---

## Syntax

```python
random.randint(start, end)
```

- **start** → Lower limit (included)
- **end** → Upper limit (included)

---

## Example

```python
import random

print(random.randint(1, 6))
```

Possible Output:

```
4
```

(Every execution may produce a different number.)

---

## Interview Questions

### Q1. Which module is used to generate random numbers?
**Answer:** `random`

### Q2. Is `randint(a, b)` inclusive?
**Answer:** Yes. Both `a` and `b` are included.

### Q3. What is the difference between `randint()` and `randrange()`?

| `randint()` | `randrange()` |
|-------------|---------------|
| Includes both start and end values | End value is excluded |
| `random.randint(1, 10)` | `random.randrange(1, 10)` |

Example:

```python
random.randint(1, 10)    # 1 to 10
random.randrange(1, 10)  # 1 to 9
```

---

## Key Points

- Import the `random` module before using random functions.
- `randint(a, b)` generates a random integer.
- Both `a` and `b` are included in the range.
- User input must be converted to integers using `int()`.
