# Heads or Tails Program

## Program

```python
import random

# Generate a random number (0 or 1)
a = random.randint(0, 1)

# Check the result
if a == 1:
    print("Heads")
else:
    print("Tails")
```

---

## Sample Output 1

```
Heads
```

---

## Sample Output 2

```
Tails
```

*(The output changes each time the program runs.)*

---

# Explanation

```python
import random
```

Imports Python's built-in **random** module.

---

## Generate a Random Number

```python
a = random.randint(0, 1)
```

Generates a random integer:

- `0`
- `1`

Both values have an equal chance of being selected.

Example:

```
0
```

or

```
1
```

---

## Check the Result

```python
if a == 1:
    print("Heads")
else:
    print("Tails")
```

If the random number is:

- `1` → Print **Heads**
- `0` → Print **Tails**

---

# Flow of the Program

```
Start
   │
Generate random number (0 or 1)
   │
   ├── 1 → Heads
   │
   └── 0 → Tails
```

# Interview Questions

### Q1. Which module is used to generate random values?

**Answer:**

```python
random
```

---

### Q2. What does `random.randint(0, 1)` return?

**Answer:**

A random integer:

- `0`
- `1`

Both values are equally likely.

---

### Q3. Why is an `if` statement used?

**Answer:**

To check whether the random value is `1` or `0` and print the corresponding result.

---

### Q4. What happens if the random number is `0`?

**Answer:**

The `else` block executes and prints:

```
Tails
```

---

# Key Points

- Import the `random` module before using random functions.
- `random.randint(0, 1)` generates either `0` or `1`.
- `if` checks whether the value is `1`.
- `else` handles the case when the value is `0`.
- Each program execution may produce a different result, simulating a fair coin toss.
