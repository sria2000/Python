# Python Random Module - Selecting Random Items from a List

## What is the `random` module?

The Python **random module** is used to generate random numbers and select random items.

To use it:

```python
import random
```

---

# Example: Print a Random Name from a List

```python
import random

random_people = [
    "Sri",
    "Ram",
    "Satish",
    "Durai",
    "Ramesh",
    "Lakshman",
    "Sita",
    "Geetha",
    "Preetha"
]

length = len(random_people)

random_length = random.randint(0, length-1)

print(random_people[random_length])
```

---

## How it Works

### Step 1: Create a List

```python
random_people = [
    "Sri",
    "Ram",
    "Satish"
]
```

A list stores multiple values using indexes.

Example:

| Index | Name |
|---|---|
| 0 | Sri |
| 1 | Ram |
| 2 | Satish |
| 3 | Durai |
| 4 | Ramesh |
| 5 | Lakshman |
| 6 | Sita |
| 7 | Geetha |
| 8 | Preetha |

---

### Step 2: Find List Length

```python
length = len(random_people)
```

`len()` returns the number of items in the list.

Output:

```
9
```

---

### Step 3: Generate a Random Index

```python
random_length = random.randint(0, length-1)
```

`random.randint(start, end)` generates a random integer between two values.

Example:

```python
random.randint(0,8)
```

Possible output:

```
0
1
2
3
...
8
```

---

### Step 4: Access Random List Item

```python
print(random_people[random_length])
```

If:

```python
random_length = 3
```

Python executes:

```python
print(random_people[3])
```

Output:

```
Durai
```

---

# Using `random.choice()`

Python provides an easier way to select a random item from a list.

Example:

```python
print("Usage of Random choice")

print(random.choice(random_people))
```

Possible Output:

```
Geetha
```

or

```
Sri
```

or

```
Ramesh
```

The result changes every time the program runs.

---

# Difference Between `randint()` and `choice()`

| Method | Purpose | Example |
|---|---|---|
| `random.randint()` | Generates a random number | `random.randint(1,10)` |
| `random.choice()` | Selects random item from a sequence | `random.choice(list)` |

---

# Example: Random Number

```python
import random

number = random.randint(1,100)

print(number)
```

Possible output:

```
57
```

# Example: Random Choice from List

```python
import random

fruits = [
    "Apple",
    "Banana",
    "Orange",
    "Mango"
]

print(random.choice(fruits))
```

Possible output:

```
Mango
```

# Interview Notes

## Q1: How do you select a random item from a Python list?

Using:

```python
random.choice(list_name)
```

Example:

```python
random.choice(random_people)
```

---

## Q2: What does `random.randint(0, length-1)` do?

It generates a random valid index number for the list.

Example:

For a list with 9 items:

```python
random.randint(0,8)
```

returns an index between:

```
0 to 8
```

---

## Q3: Why do we use `length-1`?

Because Python list indexes start from `0`.

Example:

```
List length = 9

Valid indexes:

0,1,2,3,4,5,6,7,8
```

The last index is always:

```
length - 1
```
