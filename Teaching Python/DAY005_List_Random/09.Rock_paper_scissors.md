# Python Project - Rock Paper Scissors Game

## Overview

This is a simple **Rock Paper Scissors** game written in Python.

The user chooses:

```
1 - Rock
2 - Paper
3 - Scissors
```

The computer randomly selects one option.

The winner is decided using the rules:

```
Rock beats Scissors
Scissors beats Paper
Paper beats Rock
```

---

# Game Rules

| User Choice | Computer Choice | Result |
|---|---|---|
| Rock | Scissors | User Wins |
| Scissors | Paper | User Wins |
| Paper | Rock | User Wins |
| Same Choice | Same Choice | Tie |
| Rock | Paper | User Loses |
| Paper | Scissors | User Loses |
| Scissors | Rock | User Loses |

---

# Interview Questions

## Q1: Why do we use `int(input())`?

Because `input()` always returns a string.

Example:

```python
input()
```

returns:

```
"1"
```

`int()` converts it:

```
1
```

so we can compare numbers.

---

## Q2: What does `random.choice()` do?

It selects a random item from a list.

Example:

```python
random.choice(
    ["Rock","Paper","Scissors"]
)
```

---

## Q3: Why use `user_input - 1`?

Because Python lists start with index `0`.

Example:

```
User enters 1

List index is 0

Rock is selected
```

---

## Q4: How can this game be simplified?

Instead of many `if` statements, we can use a dictionary:

```python
winning_rules = {
    "Rock":"Scissors",
    "Paper":"Rock",
    "Scissors":"Paper"
}
```

Then:

```python
if winning_rules[user_choice] == computer_choice:
    print("You win")
```
