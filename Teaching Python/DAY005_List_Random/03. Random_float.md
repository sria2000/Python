# Generate Random Floating-Point Numbers

## Program

```python
import random

# Random floating-point number between 0 and 1
random_number_0_to_1 = random.random()
print(random_number_0_to_1)

# Random floating-point number between 1 and 10
random_float = random.uniform(1, 10)
print(random_float)
```

---

## Sample Output

```
0.6845172934218956
7.238941502184913
```

*(Your output will be different each time the program runs.)*

---

# Explanation

```python
import random
```

Imports Python's built-in **random** module.

---

## 1. `random.random()`

```python
random_number_0_to_1 = random.random()
```

Generates a **random floating-point number** between:

```
0.0 <= number < 1.0
```

- Includes **0.0**
- Excludes **1.0**

Example outputs:

```
0.2543
0.7812
0.9998
```

---

## 2. `random.uniform(a, b)`

```python
random_float = random.uniform(1, 10)
```

Generates a random floating-point number between **1** and **10**.

Example outputs:

```
2.45
5.98
9.81
1.02
```

Both endpoints (`1` and `10`) can be returned.

---

# Syntax

## `random.random()`

```python
random.random()
```

Returns:

```
0.0 <= number < 1.0
```

---

## `random.uniform(a, b)`

```python
random.uniform(start, end)
```

Returns:

```
start <= number <= end
```

---

# Difference Between `random()` and `uniform()`

| Function | Range | Return Type |
|----------|-------|-------------|
| `random.random()` | 0.0 to less than 1.0 | Float |
| `random.uniform(a, b)` | Between `a` and `b` | Float |

# Interview Questions

### Q1. What does `random.random()` return?

**Answer:**

A random floating-point number between **0.0 (inclusive)** and **1.0 (exclusive)**.

---

### Q2. What does `random.uniform(a, b)` return?

**Answer:**

A random floating-point number between **a** and **b**.

---

### Q3. Which function generates a decimal number between 0 and 1?

**Answer:**

```python
random.random()
```

---

### Q4. Which function generates a decimal number between any two values?

**Answer:**

```python
random.uniform(a, b)
```

---

# Key Points

- Import the `random` module before using random functions.
- `random.random()` returns a float between **0.0** and **less than 1.0**.
- `random.uniform(a, b)` returns a float between **a** and **b**.
- Every execution generates different random values.
- Both functions return **floating-point (decimal)** numbers.
