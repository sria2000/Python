# 12) Exercise - Band Name Generator

## Question

Create a program that generates a band name.

### Program Flow

1. Display a welcome message.
2. Ask the user for the name of the city they grew up in.
3. Ask the user for their pet's name.
4. Combine both answers to create a band name.

---

## Example Run

```
Welcome to Band Name Generator

What's the name of the city you grew up in?
London

What's your pet's name?
Charlie

Your band name could be London Charlie
```

---

## Solution

```python
print("Welcome to Band Name Generator")

city = input("What's the name of the city you grew up in?\n")
pet = input("What's your pet's name?\n")

print("Your band name could be " + city + " " + pet)
```

---

## Sample Output

```
Welcome to Band Name Generator
What's the name of the city you grew up in?
London
What's your pet's name?
Charlie
Your band name could be London Charlie
```

---

## What You Learned

- `print()` displays output on the screen.
- `input()` accepts user input.
- Variables (`city` and `pet`) store user input.
- The `+` operator concatenates (joins) strings.
- `" "` adds a space between the city and pet name.
