# Exercise - Swap Two Variables

## Question

You have two variables:

- `glass1` contains **milk**
- `glass2` contains **juice**

Write **3 lines of code** to switch the contents of the variables.

### Rules

- ❌ Do **not** type the words `"milk"` or `"juice"` while swapping.
- ✅ Use only variables to solve the exercise.

---

## Initial Code

```python
glass1 = "milk"
glass2 = "juice"
```

---

## Solution

```python
glass1 = "milk"
glass2 = "juice"

glass_temp = glass2
glass2 = glass1
glass1 = glass_temp

print(glass1, glass2)
```

---

## Output

```
juice milk
```

---

## How It Works

Initially:

```
glass1 → milk
glass2 → juice
```

Store the contents of `glass2` in a temporary variable:

```
glass_temp → juice
```

Copy `glass1` into `glass2`:

```
glass2 → milk
```

Finally, copy the temporary value back into `glass1`:

```
glass1 → juice
```

The values have now been successfully swapped.

---

## Memory Trick

Think of moving water between two glasses:

```
Glass 1 (Milk)  ──► Temporary Glass
Glass 2 (Juice) ─► Glass 1
Temporary Glass ─► Glass 2
```

Without the temporary variable, one of the values would be overwritten and lost.
