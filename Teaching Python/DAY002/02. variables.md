# 3) String Concatenation

### Code

```python
print("Hello" " " + "Sri")
```

### Output

```
Hello Sri
```

### Explanation

Python automatically joins adjacent strings.

```python
"Hello" " "
```

becomes

```python
"Hello "
```

which is then concatenated with `"Sri"`.

# 4) Fix the Indentation Error

### Incorrect Code

```python
print("Hello World\n Hello World")
 print("Hello" " " + "Sri")
```

### Error

```
IndentationError: unexpected indent
```

### Why?

The second line starts with an extra space.

Python thinks you're starting a code block, but no block exists.

### Solution

```python
print("Hello World\n Hello World")
print("Hello" " " + "Sri")
```

### Output

```
Hello World
 Hello World
Hello Sri
```

# 5) Fix the Syntax Error

### Incorrect Code

```python
print("Hello World\n Hello World)"
print("Hello" " " + "Sri")
```

### Error

```
SyntaxError: '(' was never closed
```

### Why?

The closing double quote is missing.

### Solution

```python
print("Hello World\n Hello World")
print("Hello" " " + "Sri")
```

# 10) Variable Naming

Variables should have **meaningful names** so that anyone reading your code can understand what they represent.

## Bad Example

```python
L = "Sri"
A = 23
```

### Why is this bad?

When someone reads the code later, they won't know what `L` or `A` represent.

- Does `L` mean **Location**, **Length**, or **Last Name**?
- Does `A` mean **Age**, **Amount**, or **Address**?

Single-letter variable names should generally be avoided unless they are used as loop counters (like `i` or `j`).

---

## Good Example

```python
name = "Sri"
age = 23
```

Now it is immediately clear that:

- `name` stores a person's name.
- `age` stores a person's age.

---

## More Examples

### Bad

```python
x = 15000
y = "London"
z = True
```

### Good

```python
salary = 15000
city = "London"
is_employee = True
```

---

## Variable Naming Rules

- Variable names can contain:
  - Letters (`a-z`, `A-Z`)
  - Numbers (`0-9`)
  - Underscores (`_`)

- Variable names **cannot**:
  - Start with a number
  - Contain spaces
  - Use special characters like `@`, `#`, `%`, `!`

### Valid Variable Names

```python
first_name = "Sri"
age = 23
student1 = "John"
total_marks = 450
```

### Invalid Variable Names

```python
1name = "Sri"      # Starts with a number
first name = "Sri" # Contains a space
my-age = 23        # Hyphen is not allowed
@name = "Sri"      # Special character
```

---

## Python Naming Convention (Best Practice)

Python programmers use **snake_case** for variable names.

```python
first_name = "Sri"
last_name = "Varadharajan"
employee_salary = 80000
number_of_students = 35
```

Avoid using:

```python
FirstName
FIRSTNAME
firstName
```

unless required by a specific coding standard.

---

## Summary

✔ Use meaningful variable names.

✔ Follow the **snake_case** naming convention.

✔ Avoid single-letter variable names unless appropriate.
