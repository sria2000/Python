# Python Data Types & Type Conversion

## 1. `len()` Works Only with Sequences

The `len()` function returns the number of items in an object such as a string, list, tuple, or dictionary.

### ❌ Incorrect

```python
print(len(123))
```

Output:

```text
TypeError: object of type 'int' has no len()
```

**Reason:**
- `123` is an integer.
- Integers do not have a length.

### ✅ Fix

Convert the integer to a string.

```python
print(len(str(123)))
```

Output:

```text
3
```

or simply

```python
print(len("123"))
```

Output:

```text
3
```

---

## 2. String Indexing

Every character in a string has an index.

```python
text = "Hello"
```

| Character | H | e | l | l | o |
|-----------|---|---|---|---|---|
| Index     | 0 | 1 | 2 | 3 | 4 |
| Negative Index | -5 | -4 | -3 | -2 | -1 |

### First Character

```python
print("Hello"[0])
```

Output

```text
H
```

### Last Character

```python
print("Hello"[4])
```

or

```python
print("Hello"[-1])
```

Output

```text
o
```

> **Tip:** Python indexing always starts at **0**, not 1.

---

## 3. String vs Integer Addition

### Strings

```python
print("123" + "345")
```

Output

```text
123345
```

The `+` operator joins (concatenates) strings.

### Integers

```python
print(123 + 345)
```

Output

```text
468
```

The `+` operator performs mathematical addition on numbers.

# Python Data Types

## String (`str`)

A sequence of characters.

```python
name = "Python"
```

Examples

```python
print("Hello")
print("123")
```

---

## Integer (`int`)

Whole numbers.

```python
age = 25
number = 1234
large_number = 12345678
```

Examples

```python
print(100)
print(-45)
```

---

## Float (`float`)

Numbers containing decimal points.

```python
pi = 3.14
price = 7.89
temperature = -2.5
```

---

## Boolean (`bool`)

Only two possible values.

```python
print(True)
print(False)
```

Used in comparisons and conditions.

```python
is_logged_in = True
is_admin = False
```

# Checking Data Types

Use the `type()` function.

### String

```python
print(type("Hello"))
```

Output

```text

```

### Integer

```python
print(type(123))
```

Output

```text
<class 'int'>
```

### Float

```python
print(type(12.34))
```

Output

```text
<class 'float'>
```

### Boolean

```python
print(type(True))
```

Output

```text
<class 'bool'>
```

# Type Conversion (Type Casting)

Python lets you convert one data type into another.

## Convert String to Integer

```python
print(int("123") + int("345"))
```

Output

```text
468
```

---

## Invalid Conversion

```python
print(int("abc"))
```

Output

```text
ValueError: invalid literal for int() with base 10: 'abc'
```

Only numeric strings can be converted to integers.

---

## Convert Numbers to Strings

```python
print(str(123) + str(345))
```

Output

```text
123345
```

---

## More Examples

### Integer to Float

```python
print(float(100))
```

Output

```text
100.0
```

---

### Float to Integer

```python
print(int(9.99))
```

Output

```text
9
```

> **Note:** `int()` removes the decimal portion. It does **not** round the number.

---

### Integer to Boolean

```python
print(bool(1))
print(bool(0))
```

Output

```text
True
False
```

---

### String to Boolean

```python
print(bool(""))
print(bool("Python"))
```

Output

```text
False
True
```

# Common Beginner Mistakes

### ❌ Using `len()` on an integer

```python
len(123)
```

✔ Convert to string first.

```python
len(str(123))
```

---

### ❌ Adding a string and an integer

```python
print("Age: " + 25)
```

Output

```text
TypeError
```

✔ Convert the integer to a string.

```python
print("Age: " + str(25))
```

or simply

```python
print("Age:", 25)
```

---

### ❌ Converting non-numeric text to an integer

```python
int("hello")
```

Output

```text
ValueError
```

# Tips for Beginners

- Python indexing starts at **0**.
- Use **negative indexes** to access characters from the end (`-1` is the last character).
- `len()` works on strings, lists, tuples, dictionaries, etc.—**not** on integers or floats.
- `+` joins **strings** but adds **numbers**.
- Use `type()` whenever you're unsure about a variable's data type.
- `print()` can display multiple values separated by commas without using `str()`.
- Use `str()` when joining text with numbers using the `+` operator.
- `int()` only converts valid numeric strings (e.g., `"123"`), not `"abc"`.
- Remember the four basic Python data types:
  - `str` → Text
  - `int` → Whole Numbers
  - `float` → Decimal Numbers
  - `bool` → True/False
