# Python Project - Tip Calculator

This project calculates how much each person should pay after adding a tip to the total restaurant bill.

---

# Problem Statement

Create a Python program that:

- Accepts the total bill amount.
- Asks the user what percentage tip they would like to give (10%, 12%, or 15%).
- Asks how many people will split the bill.
- Calculates the total amount including the tip.
- Displays how much each person should pay.

---

# Python Program

```python
print("Welcome to the Tip Calculator!")

bill = float(input("How much was the total bill (£)? "))

tip = int(input("How much tip would you like to give? 10, 12 or 15? "))

tip_amount = bill * (tip / 100)

num_of_people = int(input("How many people are splitting the bill? "))

total_amount = bill + tip_amount

per_person = round(total_amount / num_of_people, 2)

print(f"Each person should pay £{per_person:.2f}")
```

# Tips for Beginners

- Use `float()` when accepting money because it may include decimal values.
- Use `int()` for whole numbers such as the tip percentage and number of people.
- `tip / 100` converts a percentage into a decimal.
- `round(number, 2)` rounds the value to two decimal places.
- `:.2f` ensures the output always displays exactly two decimal places.
- Use meaningful variable names such as `bill`, `tip_amount`, `total_amount`, and `per_person` to make your code easy to understand.

---

# Common Beginner Mistakes

### ❌ Forgetting to Convert User Input

```python
bill = input("Enter bill: ")
```

This stores the input as a **string**, not a number.

Correct

```python
bill = float(input("Enter bill: "))
```

---

### ❌ Using Integer Division

Avoid using floor division (`//`) for money calculations.

Incorrect

```python
per_person = total_amount // num_of_people
```

This removes the decimal portion.

Correct

```python
per_person = total_amount / num_of_people
```

---

### ❌ Forgetting to Round the Result

Without rounding

```python
print(per_person)
```

Output

```text
33.333333333333336
```

Better

```python
print(round(per_person, 2))
```

or

```python
print(f"{per_person:.2f}")
```
