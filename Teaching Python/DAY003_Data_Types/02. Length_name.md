# Find the Number of Letters in Your Name

This example demonstrates two ways to display the number of characters entered by the user.

---

## Method 1 – Using a Comma (Recommended)

```python
print("Number of letters in your name", len(input("Enter your name: ")))
```

### Example

**Input**

```text
Enter your name: Sriram
```

**Output**

```text
Number of letters in your name 7
```

### How it Works

1. `input()` accepts the user's name as a **string**.
2. `len()` counts the number of characters in that string.
3. `print()` displays both values because they are separated by a comma.
4. No type conversion is required because `print()` automatically handles different data types.

---

## Method 2 – Using String Conversion

```python
print("Number of letters in your name: " + str(len(input("Enter your name: "))))
```

### Example

**Input**

```text
Enter your name: Sriram
```

**Output**

```text
Number of letters in your name: 7
```

### How it Works

- `len()` returns an **integer**.
- The `+` operator can only join **strings**.
- Therefore, `str()` converts the integer into a string before concatenation.

---

## Why Doesn't Method 1 Need `str()`?

This works:

```python
print("Age:", 25)
```

because `print()` accepts multiple arguments separated by commas and automatically displays them.

This does **not** work:

```python
print("Age: " + 25)
```

Output

```text
TypeError: can only concatenate str (not "int") to str
```

Fix it by converting the integer to a string:

```python
print("Age: " + str(25))
```

---

## Comparison

| Method | Example | Need `str()`? |
|---------|---------|---------------|
| Using comma | `print("Age:", 25)` | ❌ No |
| Using `+` | `print("Age: " + str(25))` | ✅ Yes |

---

## Beginner Tips

- `input()` always returns a **string**.
- `len()` always returns an **integer**.
- Use a **comma** inside `print()` when printing different data types together.
- Use `str()` when joining text with numbers using the `+` operator.
- The unary `+` before `len()` (e.g., `+len(...)`) is optional and has no effect. These are equivalent:

```python
print("Number of letters in your name", +len(input("Enter your name: ")))
```

```python
print("Number of letters in your name", len(input("Enter your name: ")))
```

The second version is cleaner and is the preferred style.
