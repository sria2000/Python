# Python Program - Calculate BMI (Body Mass Index)

BMI (Body Mass Index) is a measure used to determine whether a person's weight is appropriate for their height.

## BMI Formula

```
BMI = Weight (kg) / Height² (m²)
```

---

# Python Program

```python
# Program to calculate BMI

# BMI = weight / (height × height)

height = float(input("Enter your height in metres: "))
print(type(height))

weight = float(input("Enter your weight in kg: "))

square_height = height ** 2
bmi = weight / square_height

print("Your BMI is:", bmi)
```

---

# Example

### Input

```text
Enter your height in metres: 1.75
Enter your weight in kg: 70
```

### Calculation

```
Height² = 1.75 × 1.75
         = 3.0625

BMI = 70 / 3.0625
    = 22.857...
```

### Output

```text
Your BMI is: 22.857142857142858
```

# Understanding the Code

### Step 1 - Read Height

```python

- `input()` reads the value as a string.
- `float()` converts it into a decimal number.

Example

```
Input: "1.75"

Stored value: 1.75

# BMI Categories (General Guidelines)

| BMI | Category |
|------|----------|
| Less than 18.5 | Underweight |
| 18.5 – 24.9 | Normal Weight |
| 25 – 29.9 | Overweight |
| 30 or above | Obese |

---

# Tips for Beginners

- `input()` always returns a **string**.
- Use `float()` when accepting decimal values like height or weight.
- `**` means "raised to the power."
- `height ** 2` means **height × height**.
- Use `round(number, 2)` to display only two decimal places.
- Variable names such as `height`, `weight`, and `bmi` make your code easier to read.
