# Python Mathematical Operators

Python supports all the common mathematical operators used in arithmetic calculations.

---

# Addition (`+`)

Adds two numbers.

```python
print("Addition")
print(3 + 4)
```

Output

```text
Addition
7
```

---

# Subtraction (`-`)

Subtracts one number from another.

```python
print("Subtraction")
print(10 - 7)
print(3 - 4)
```

Output

```text
Subtraction
3
-1
```

---

# Multiplication (`*`)

Multiplies two numbers.

```python
print("Multiplication")
print(3 * 4)
```

Output

```text
Multiplication
12
```

---

# Division (`/`)

Performs normal division.

The result is always a **float**, even when the answer is a whole number.

```python
print("Division")
print(14 / 3)
print(15 / 3)
```

Output

```text
Division
4.666666666666667
5.0
```

---

# Floor Division (`//`)

Returns only the whole number portion of the division.

The decimal (remainder) is discarded.

```python
print("Floor Division")
print(6 // 3)
print(5 // 3)
```

Output

```text
Floor Division
2
1
```

Explanation

```
6 ÷ 3 = 2.0  → 2
5 ÷ 3 = 1.666... → 1
```

---

# Modulus (`%`)

Returns the remainder after division.

```python
print("Modulus")
print(10 % 3)
print(20 % 5)
```

Output

```text
Modulus
1
0
```

Uses:
- Check if a number is even or odd.
- Find remainders.

Example

```python
print(8 % 2)
```

Output

```text
0
```

Since the remainder is **0**, 8 is an even number.

---

# Exponentiation (`**`)

Raises a number to the power of another.

```python
print("Exponentiation")
print(2 ** 3)
print(5 ** 2)
```

Output

```text
Exponentiation
8
25
```

---

# Operator Precedence (PEMDAS / BODMAS / BIDMAS)

Python follows the standard order of operations.

1. **P** - Parentheses `()`
2. **E** - Exponents `**`
3. **MD** - Multiplication `*`, Division `/`, Floor Division `//`, Modulus `%` (left to right)
4. **AS** - Addition `+`, Subtraction `-` (left to right)

---

## Example 1

```python
print(3 * 3 + 3 / 3 - 3)
```

Calculation

```
3 * 3 = 9
3 / 3 = 1.0

9 + 1.0 - 3
= 7.0
```

Output

```text
7.0
```

---

## Example 2 - Using Parentheses

Change the code to produce an output of **3**.

```python
print(3 * (3 + 3) / 3 - 3)
```

Calculation

```
(3 + 3) = 6

3 * 6 = 18

18 / 3 = 6.0

6.0 - 3 = 3.0
```

Output

```text
3.0
```

# Tips for Beginners

- `/` always returns a **float**.
- `//` removes the decimal portion (it does **not** round).
- `%` returns the remainder after division.
- `**` means "raised to the power of."
- Use parentheses `()` to make calculations easier to read and to change the order of evaluation.
- Python follows **PEMDAS/BODMAS**, so multiplication and division happen before addition and subtraction.
