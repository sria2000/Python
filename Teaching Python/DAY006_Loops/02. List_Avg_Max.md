# Python Lists - Sum, Average and Maximum Value

## Overview

In this example, we will learn how to:

- Find the **sum** of numbers using `sum()`
- Calculate the **average**
- Find the **maximum** value using `max()`
- Calculate the **sum manually** using a `for` loop
- Find the **maximum manually** using a `for` loop

---

# Example Program

```python
student_scores = [
    118, 53, 714, 355, 728,
    414, 215, 495, 18, 892,
    757, 558, 508, 470, 812,
    126, 495, 940, 828, 663
]

total = sum(student_scores)
print("Total is", total)

average = total / len(student_scores)
print("Average is", average)

max_score = max(student_scores)
print("Max is", max_score)

# Calculate total manually
total = 0

for score in student_scores:
    total = total + score

print("Total is", total)

# Calculate maximum manually
max_in_list = 0

for score in student_scores:
    if score > max_in_list:
        max_in_list = score

print("Max is", max_in_list)
```

>

# Finding the Total Using `sum()`

Python provides the built-in `sum()` function.

```python
total = sum(student_scores)
```

It adds all the numbers in the list.

Example:

```python
numbers = [10,20,30]

print(sum(numbers))
```

Output:

```text
60
```

---

# Finding the Average

Average is calculated using:

```
Average = Total ÷ Number of Items
```

Python code:

```python
average = total / len(student_scores)
```

Explanation:

- `total` = Sum of all scores
- `len(student_scores)` = Number of students

---

# Using `len()`

```python
len(student_scores)
```

returns:

```
20
```

because there are 20 numbers in the list.

---

# Finding the Maximum Using `max()`

Python has a built-in function:

```python
max(student_scores)
```

Output:

```text
940
```

This returns the largest value in the list.

---

# Calculating the Sum Manually

Instead of using `sum()`, we can calculate it ourselves.

```python
total = 0

for score in student_scores:
    total = total + score
```

### How It Works

Initially:

```python
total = 0
```

Loop execution:

| Score | Running Total |
|------:|--------------:|
| 118 | 118 |
| 53 | 171 |
| 714 | 885 |
| 355 | 1240 |
| ... | ... |
| 940 | Final Total |

Each loop adds the current score to the running total.

---

# Finding the Maximum Manually

Instead of using `max()`, we compare each number.

```python
max_in_list = 0

for score in student_scores:
    if score > max_in_list:
        max_in_list = score
```

### Step-by-Step

Start:

```python
max_in_list = 0
```

Loop:

| Current Score | Current Max | New Max |
|--------------:|------------:|---------|
| 118 | 0 | 118 |
| 53 | 118 | 118 |
| 714 | 118 | 714 |
| 355 | 714 | 714 |
| 892 | 714 | 892 |
| 940 | 892 | 940 |

Final answer:

```
940
```

# Built-in Functions Used

| Function | Purpose | Example |
|---|---|---|
| `sum()` | Adds all numbers | `sum(numbers)` |
| `len()` | Counts items | `len(numbers)` |
| `max()` | Returns largest value | `max(numbers)` |

---

# Manual vs Built-in Functions

| Task | Built-in Function | Manual Method |
|---|---|---|
| Total | `sum(list)` | `for` loop |
| Average | `sum()/len()` | Running total ÷ count |
| Maximum | `max(list)` | Compare each value |

---

# Common Mistake

Avoid using:

```python
sum = 0
```

because `sum` is already a built-in Python function.

Instead, use:

```python
total = 0
```

or

```python
running_total = 0
```

This prevents accidentally overwriting the built-in `sum()` function.

# Interview Questions

## Q1: How do you find the sum of a list?

Using:

```python
sum(student_scores)
```

---

## Q2: How do you calculate the average?

```python
average = sum(student_scores) / len(student_scores)
```

---

## Q3: How do you find the largest number?

Using:

```python
max(student_scores)
```

or manually:

```python
largest = 0

for score in student_scores:
    if score > largest:
        largest = score
```

---

## Q4: Why is `max_in_list` initialized to `0`?

It provides a starting value for comparison.

> **Better Practice:** If the list could contain negative numbers, initialize with the first element:

```python
max_in_list = student_scores[0]
```

This works correctly for both positive and negative values.

---

## Q5: Why should you avoid naming a variable `sum`?

Because `sum` is a built-in Python function.

Bad:

```python
sum = 0
```

Good:

```python
total = 0
```

---

# Key Points

- `sum()` calculates the total.
- `len()` returns the number of elements.
- Average = Total ÷ Count.
- `max()` returns the largest value.
- A `for` loop can calculate totals manually.
- A `for` loop with an `if` statement can find the maximum value manually.
- Avoid naming variables `sum`, `max`, or `list` because they are built-in Python names.
