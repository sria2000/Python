# Python Lists with `for` Loops

## Overview

A **`for` loop** is used to iterate (loop) through each item in a list.

Instead of accessing each item by its index, Python automatically gives you one item at a time.

---

# Example

```python
fruits = ["apple", "banana", "cherry"]

for fruit in fruits:
    print(fruit)
    print(fruit + " pie")

print(fruits)
```

---

# Output

```text
apple
apple pie
banana
banana pie
cherry
cherry pie

['apple', 'banana', 'cherry']
```

---

# Understanding the Code

## Step 1: Create a List

```python
fruits = ["apple", "banana", "cherry"]
```

The list contains three items.

| Index | Value |
|------:|-------|
| 0 | apple |
| 1 | banana |
| 2 | cherry |

---

## Step 2: Loop Through the List

```python
for fruit in fruits:
```

Python reads this as:

> "For every item in the `fruits` list, store it in the variable `fruit`."

During each iteration:

### First Iteration

```python
fruit = "apple"
```

Output:

```text
apple
apple pie
```

---

### Second Iteration

```python
fruit = "banana"
```

Output:

```text
banana
banana pie
```

---

### Third Iteration

```python
fruit = "cherry"
```

Output:

```text
cherry
cherry pie
```

---

# What Does This Line Do?

```python
print(fruit + " pie")
```

Python joins (concatenates) two strings together.

Example:

```python
fruit = "apple"

print(fruit + " pie")
```

Output:

```text
apple pie
```

Similarly:

```python
banana + " pie"
```

becomes:

```text
banana pie
```

---

# What Does This Print?

```python
print(fruits)
```

Output:

```text
['apple', 'banana', 'cherry']
```

Notice that this prints the **entire list**, not individual items.

---

# Loop Flow

```
fruits

│
├── apple
│      ↓
│   print(apple)
│   print(apple pie)
│
├── banana
│      ↓
│   print(banana)
│   print(banana pie)
│
└── cherry
       ↓
    print(cherry)
    print(cherry pie)
```

# Loop Using `range()`

You can also loop using indexes.

```python
fruits = ["apple", "banana", "cherry"]

for i in range(len(fruits)):
    print(i, fruits[i])
```

Output:

```text
0 apple
1 banana
2 cherry
```

---

# `for item in list` vs `for i in range(len(list))`

| Method | Example | Best Use |
|---|---|---|
| Loop through values | `for fruit in fruits` | When you only need the values |
| Loop through indexes | `for i in range(len(fruits))` | When you need both index and value |

---

# Common Mistake

❌ Incorrect:

```python
for fruits in fruit:
```

This causes an error because `fruit` does not exist.

✅ Correct:

```python
for fruit in fruits:
```

# Interview Questions

## Q1: What does `for fruit in fruits` do?

It loops through each item in the `fruits` list one by one.

---

## Q2: Is `fruit` a keyword?

No.

`fruit` is just a variable name.

These are all valid:

```python
for x in fruits:
```

```python
for item in fruits:
```

```python
for name in fruits:
```

---

## Q3: How many times will the loop execute?

```python
fruits = ["apple", "banana", "cherry"]
```

The loop runs **3 times** because there are **3 items** in the list.

---

## Q4: What does `print(fruits)` print?

It prints the **entire list**.

Output:

```text
['apple', 'banana', 'cherry']
```

---

## Q5: What is string concatenation?

Joining two strings together.

Example:

```python
print("apple" + " pie")
```

Output:

```text
apple pie
```

---

# Key Points

- A `for` loop iterates through each item in a list.
- The loop variable (e.g., `fruit`) holds one item at a time.
- `print(fruit)` prints the current item.
- `print(fruit + " pie")` joins two strings together.
- `print(fruits)` prints the complete list.
- You can loop through values directly or use indexes with `range(len(list))`.
