# Python Project - FizzBuzz

## Overview

**FizzBuzz** is one of the most common beginner Python programs and is frequently asked in coding interviews.

The goal is to print numbers from **1 to 100** while replacing certain numbers with words according to these rules.

---

# FizzBuzz Rules

Print numbers from **1 to 100**.

However:

- If a number is divisible by **3**, print **"Fizz"**
- If a number is divisible by **5**, print **"Buzz"**
- If a number is divisible by **both 3 and 5**, print **"FizzBuzz"**
- Otherwise, print the number itself

---

# Example Program

```python
for number in range(1, 101):

    if number % 3 == 0 and number % 5 == 0:
        print("FizzBuzz")

    elif number % 5 == 0:
        print("Buzz")

    elif number % 3 == 0:
        print("Fizz")

    else:
        print(number)
```

> **Note:** The line:
>
> ```python
> number = 0
> ```
>
> before the loop is **not required**, because the `for` loop automatically assigns values to `number`.

# Checking Divisibility

The `%` operator is called the **modulus operator**.

It returns the remainder after division.

Example:

```python
6 % 3
```

Output:

```
0
```

because 6 is exactly divisible by 3.

---

Another example:

```python
7 % 3
```

Output:

```
1
```

because:

```
7 ÷ 3 = 2 remainder 1
```

# Why Is `FizzBuzz` Checked First?

Suppose the number is:

```
15
```

If we checked:

```python
if number % 3 == 0:
```

first,

Python would print:

```
Fizz
```

and never check whether it's also divisible by 5.

That's why the combined condition must come first:

```python
if number % 3 == 0 and number % 5 == 0:
```

Correct order:

```python
if divisible by both:
```

↓

```python
elif divisible by 5:
```

↓

```python
elif divisible by 3:
```

↓

```python
else
```

# Using the Modulus Operator `%`

| Expression | Result | Explanation |
|---|---:|---|
| `6 % 3` | 0 | Divisible by 3 |
| `10 % 5` | 0 | Divisible by 5 |
| `15 % 3` | 0 | Divisible by 3 |
| `15 % 5` | 0 | Divisible by 5 |
| `7 % 3` | 1 | Not divisible by 3 |
| `8 % 5` | 3 | Not divisible by 5 |

# Common Mistake

❌ Incorrect order:

```python
if number % 3 == 0:
    print("Fizz")

elif number % 5 == 0:
    print("Buzz")

elif number % 3 == 0 and number % 5 == 0:
    print("FizzBuzz")
```

For:

```
15
```

Output:

```
Fizz
```

because the first condition is already true.

---

✅ Correct order:

```python
if number % 3 == 0 and number % 5 == 0:
    print("FizzBuzz")

elif number % 5 == 0:
    print("Buzz")

elif number % 3 == 0:
    print("Fizz")

else:
    print(number)
```

# Interview Questions

## Q1: What is the `%` operator?

The `%` operator returns the remainder after division.

Example:

```python
10 % 3
```

Output:

```
1
```

---

## Q2: Why do we check `3` and `5` together first?

Because numbers like **15**, **30**, and **45** satisfy both conditions.

If we check only `3` first, `"FizzBuzz"` will never be printed.

---

## Q3: What does `range(1,101)` generate?

```
1
2
3
...
100
```

The stop value (`101`) is not included.

---

## Q4: Which numbers print `"Buzz"`?

Numbers divisible by **5** but **not by both 3 and 5**.

Examples:

```
5
10
20
25
35
40
```

---

## Q5: Which numbers print `"Fizz"`?

Numbers divisible by **3** but **not by both 3 and 5**.

Examples:

```
3
6
9
12
18
21
```

---

## Q6: Which numbers print `"FizzBuzz"`?

Numbers divisible by **both 3 and 5**.

Examples:

```

30
45
60
75
90
```

# Key Points

- FizzBuzz is a common coding interview exercise.
- Use a `for` loop with `range(1,101)` to print numbers from 1 to 100.
- `%` checks divisibility by finding the remainder.
- Check the **combined condition (`3` and `5`) first**.
- Use `elif` to test additional conditions.
- Use `else` to print numbers that do not match any rule.
